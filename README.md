<details open>
<summary><b>🧭 Reach features without moving your hand</b></summary>

| Feature | Description |
|---|---|
| Ring launcher | Press the left and right mouse buttons together and a ring of your 8 most-used actions opens around the cursor. Flick toward one and let go |
| Command palette | `Ctrl+Shift+P` finds and runs any action by name, description, or key — including actions with no shortcut bound |
| Keyboard shortcuts | Every action can be remapped, with JSON export and import. Shortcuts keep working during Japanese/IME input |

<details>
<summary><b>📁 File management</b></summary>

| Feature | Description |
|---|---|
| File operations | Copy, move, delete, and rename with undo. Large copies and moves show a progress window with speed and time remaining, where each job can be paused or stopped |
| Drag and drop | Between panes and with other apps; right-drag to choose the action. Dropping onto a shortcut (.lnk) uses its target |
| Batch rename | Rename many files at once with a live preview |
| Batch timestamps & attributes | Change created/modified/accessed times and attributes of many items at once, previewing exactly what will change |
| Archives | Extract and compress ZIP and other formats from the right-click menu, including straight into the other pane |
| Folder compare & sync | Compare the folders in the A and B panes by size, time, or content hash, then sync A → B |

| FTP / SFTP / FTPS | Server folders open in a pane just like local ones |

## Latest changes

<details>
<summary><b>Show the notes for the latest release</b></summary>

<!-- latest-changes-en:begin -->
**[1.16.5] - 2026-09-26 : The first-launch guide becomes "First 5 steps" that you complete as you use the app, the nav icon bar gains a ≫ for views that do not fit, you can add extensions for "Open in text editor", and auto-hidden nav panes and dialog title bars are fixed**

### Added

- **You can now add extensions that show "Open in text editor" (#352)** — "Open in text editor" on the right-click menu appeared only for a fixed set of extensions such as `.txt`, `.md` and `.json`, so it could not be used to edit `.csv` or `.dat` files. Enter extensions separated by commas, such as `csv, dat`, in "Additional extensions" under Control Deck → **1. General** → Display → Text editor, and the menu appears for them too. A leading `.` or `*.` is optional. The default extensions stay as they are (they cannot be removed), and their list is shown below the field. Added extensions also become targets of "Compare Text", which puts two files side by side.

- **Views that do not fit in a nav pane icon bar can now be picked from a "≫" at its right end (#353)** — At the width the app starts with, about half of the 18 icons on the left nav pane icon bar were cut off with no sign of it. A **≫** now appears at the right end of the icon bar only when icons do not fit; click it to list the views that did not fit. Picking one switches to that view, and the view being shown is highlighted. Widen the nav pane until everything fits and the ≫ goes away. The lower icon bar works the same way. The **∨** that was already at the right end does not show more icons; it opens the menu for managing where views are placed, and it was easy to mistake for one, so the new button points the other way.

### Changed

- **The ☆ in the address bar is now filled in when the open folder is already in your favorites (#350)** — the ☆ used to look the same whether or not the folder was registered, so the only way to check was to go and look through your favorites. Opening a registered folder now fills the ☆ with the favorites colour. Colour alone would be hard to make out in some themes, where it sits close to the address bar's own colour, so the difference is in **the shape — hollow or filled**. Wherever you add or remove a favorite — deleting it in the Favorites view, dragging a folder in, and so on — the ☆ in every open tab follows straight away. Paths that differed only by a trailing `\`, such as `C:\work` and `C:\work\`, were also treated as different folders; they are now matched as the same folder, which also applies to the registered check and to duplicate detection.

- **The "Standard" nav pane layout preset now matches the layout the app starts with (#353)** — "Standard" used to cut the left icon bar down to five views and remove the right nav pane, so no preset could bring back the original layout. Picking "Standard" now returns to the starting layout: every view on the left nav pane, and History, Recent Files and more on the right. **If "Standard" is selected for Nav Pane under Startup Presets in the settings, the app will start with this layout from the next launch.** To keep the old five-view layout, set it up, save it as a preset under a name, and select that preset under Startup Presets instead.

- **The guide shown at first launch is now "First 5 steps", which you complete as you use the app, instead of a 6-step tour that locked the screen (#354)** — The old tour had several problems: its explanations were hidden behind windows such as the theme settings, the screen was locked so you could not do what it said you could "set up later", the explanation box jumped around at every step, and with the default "Plain" theme the Next and Finish labels could not be read. Now a "First 5 steps" card appears at the bottom right of the main window, listing "Open a folder and get where you need to be", "Move files by drag and drop", "Add a folder you often visit to Favorites", "Try the Ring Launcher" and "Find anything in the Command Palette". **Each one checks itself off when you actually do it.** Nothing is locked, so you keep using the app as usual. "Show me" on each row briefly highlights where to do it. When all five are done, the progress ring fills, a small celebration plays, Stickman cheers, and the card folds away. You can collapse or close the card, and if you quit halfway it picks up where you left off next time. After closing it, bring it back from "Show "First 5 steps"" under Control Deck > General, which replaces "Replay tour". It is not shown to people who already use the app. The setup screen shown before the first launch was also refreshed: progress is shown as a row of bars, page changes have a light motion, and the last page previews "First 5 steps". The start button now reads "Let's go".

### Fixed

- **Fixed toggling the nav pane from the Ring Launcher or the keyboard doing nothing while the pane is auto-hidden (#351)** — On a side with "Auto-hide left nav pane" / "Auto-hide right nav pane" turned on, pressing ◀ ▶ on the Ring Launcher or `Ctrl+Shift+[` / `Ctrl+Shift+]` did nothing. On an auto-hidden side these actions now **show the nav pane temporarily**. To close it, repeat the same action or **click outside the nav pane** (when shown this way the cursor never passes over the pane, so the usual close-on-leave does not apply). The auto-hide setting itself stays as it is. The ◀ ▶ highlight on the Ring Launcher also now matches whether the pane is actually visible on an auto-hidden side.

- **Fixed the title bar of dialogs such as confirmations, input boxes and settings not taking the theme colors (#322)** — The same problem as #319, which fixed the manual and release notes window: about 15 other dialogs, including adding to favorites, entering a name, confirming a deletion, remote connection settings and the settings of each nav pane view, kept the Windows title bar color. With dark themes in particular, the white title bar stood out. These title bars now take the theme's title bar color and text color, and open dialogs are repainted when you switch themes. On Windows 10 the title bar color cannot be set, so only a light or dark title bar is chosen to match the theme.

- **Fixed option descriptions in the Ring Launcher settings sometimes becoming hard to read when selected** — In the "Mode" (8 slots / Multi-level) and "Design" options, the description text had a fixed color, so selecting an option changed only the background and left the description behind. The description color now switches with the selection. A check meant to catch this kind of mistake had been examining nothing because of a typo, and that is fixed as well.

## 最新の変更履歴

<details>
<summary><b>最新リリースの内容を表示</b></summary>

<!-- latest-changes-ja:begin -->
**[1.16.5] - 2026-09-26 : はじめて起動したときの案内を使いながら進める「はじめの 5 つ」に作り替え、ナビのアイコンバーに入りきらないビューの ≫ と「テキストエディタで開く」の対象拡張子の追加を加え、自動で隠したナビとダイアログのタイトルバーの不具合を直した**

### Added

- **「テキストエディタで開く」を出す拡張子を、設定で足せるようにしました (#352)** — 右クリックの「テキストエディタで開く」は、`.txt`・`.md`・`.json` などあらかじめ決めた拡張子にしか出ず、`.csv` や `.dat` をエディタで直したいときに使えませんでした。Control Deck → **1. 基本設定** → 表示 → テキストエディタの「対象に足す拡張子」に、`csv, dat` のようにカンマ区切りで入れると、その拡張子にもメニューが出ます。先頭の `.` や `*.` は付けても付けなくても構いません。既定の拡張子はそのまま残り（外せません）、何が既定で入っているかは欄の下に一覧で出ます。足した拡張子は、2 つのファイルを並べる「テキスト比較」の対象にもなります。

- **ナビペインのアイコンバーに入りきらないビューを、右端の「≫」から選べるようにしました (#353)** — はじめて起動したときの幅では、左のナビペインのアイコンバーに並ぶ 18 個のうち半分ほどが、何の知らせもなく途中で切れていました。入りきらないときだけアイコンバーの右端に **≫** が出て、押すと入りきらなかったビューが一覧で出ます。選ぶとそのビューに切り替わり、表示中のビューは色付きで示します。ナビペインを広げて全部入れば ≫ は消えます。下段のアイコンバーも同じです。これまで右端にあった **∨** は続きを出すボタンではなく、ビューの置き場所を管理するメニューで、取り違えやすかったため向きの違う ≫ にしています。

### Changed

- **アドレスバーの ☆ が、お気に入りに登録済みのフォルダでは中まで塗られるようにしました (#350)** — これまで ☆ は登録済みでも未登録と同じ見た目で、開いているフォルダが登録済みかを確かめるには、お気に入りを探しに行くしかありませんでした。登録済みのフォルダを開くと、☆ の中がお気に入りの色で塗られます。色だけで示すと帯の色と見分けにくいテーマがあるため、**中が空か塗られているかの形**で分かるようにしています。お気に入りビューでの削除やドラッグでの登録など、どこから登録・解除しても、開いているタブの ☆ がすぐに追従します。あわせて、`C:\work` と `C:\work\` のように末尾の `\` の有無だけが違うパスを別のフォルダとして扱っていたのを直し、同じフォルダとして照合するようにしました（登録済みの確認や、重複登録の判定にも効きます）。

- **ナビペイン配置プリセットの「標準」を、はじめて起動したときと同じ並べ方にしました (#353)** — これまでの「標準」は、左のアイコンバーを 5 つに絞って右のナビペインを消す構成で、どのプリセットを選んでもはじめの並べ方に戻せませんでした。「標準」を選ぶと、左のナビペインに全部のビュー、右のナビペインに履歴や最近のファイルなどが並ぶ、はじめの状態に戻ります。**設定の「起動時プリセット」で、ナビペインに「標準」を選んでいる方は、次の起動からこの並べ方になります**。以前の 5 つに絞った並べ方を使い続けたいときは、その並べ方にしてからプリセットとして名前を付けて保存し、「起動時プリセット」で選び直してください。

- **はじめて起動したときの案内を、画面をロックする 6 ステップのツアーから、使いながら進める「はじめの 5 つ」に作り替えました (#354)** — これまでのツアーは、説明がテーマ設定などの窓に隠れる、画面がロックされて「あとで設定できる」と書いてあることができない、説明の窓がステップごとに跳ぶ、既定のテーマ「Plain」で［次へ］［完了］の文字が読めない、といった問題を抱えていました。新しい案内では、メイン画面の右下に「はじめの 5 つ」のカードが出ます。「フォルダを開いて目的地へ」「ドラッグ＆ドロップで移す」「よく行くフォルダをお気に入りに」「リングランチャーを使う」「コマンドパレットで探す」の 5 つで、**実際にその操作をすると自動でチェックが付きます**。画面はロックしないので、いつもどおり操作しながら進められます。各行の［やってみる］を押すと、操作する場所が数秒だけ光ります。5 つそろうと進捗の輪が満ちてお祝いの演出が出て、スティックマンも喜び、カードは小さく畳まれます。カードは畳む・閉じるができ、途中で終了しても次の起動で続きから出ます。閉じたあとは Control Deck ＞ 基本設定 の「『はじめの 5 つ』を表示」から出し直せます（これまでの「ツアーをもう一度見る」の置き換えです）。すでに使っている方には出ません。あわせて、起動前の設定の画面も見直しました。進み具合を横長のバーで示し、ページの切り替えに軽い動きを付け、最後のページで「はじめの 5 つ」を予告するようにしています。起動ボタンは「さあ、はじめよう」になりました。

### Fixed

- **ナビペインを自動的に隠しているとき、リングランチャーやキーからの表示切替が効かなかったのを直しました (#351)** — 「左ナビペインを自動的に隠す」「右ナビペインを自動的に隠す」をオンにしている側では、リングランチャーの ◀ ▶ や `Ctrl+Shift+[` / `Ctrl+Shift+]` で表示を切り替えても、何も起きませんでした。自動的に隠している側では、これらの操作で**ナビペインを一時的に出す**ようにしました。閉じるときは、もう一度同じ操作をするか、**ナビペインの外をクリック**します（キーやリングで出したときはカーソルがナビペインの上を通らないので、離れたら閉じる従来の動きでは閉じられないためです）。自動的に隠す設定そのものは変わりません。あわせて、リングランチャーの ◀ ▶ の点灯が、自動的に隠している側では実際に見えているかどうかと合っていなかったのを直しました。

- **確認・入力・各種設定などのダイアログで、タイトルバーにテーマの色が付かなかったのを直しました (#322)** — マニュアル・更新履歴のウィンドウを直した #319 と同じ問題で、ほかにもお気に入りへの登録、名前の入力、削除などの確認、リモート接続の設定、ナビペインの各ビューの設定など 15 個ほどのダイアログで、タイトルバーだけ Windows の色のまま残っていました。とくに暗いテーマでは、白いタイトルバーが浮いて見えていました。これらのタイトルバーにも、テーマのタイトルバーの色と文字色が付くようにしました。テーマを切り替えたときは、開いているダイアログも塗り直します。Windows 10 ではタイトルバーの色を指定できないため、テーマの明暗に合わせて明るい／暗いタイトルバーを切り替えるところまでになります。

- **リングランチャーの設定で、選んだ選択肢の説明文が読みにくくなることがあったのを直しました** — 「モード」（8 項目／複数階層）と「デザイン」の選択肢で、説明文の色を固定していたため、選ぶと背景だけ色が変わり、説明文が取り残されていました。選択に合わせて説明文の色も切り替わるようにしました。この種の間違いを見つけるための検査が、書き間違いで何も調べていなかったのも直しています。
