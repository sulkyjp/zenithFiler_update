## Latest changes

<details>
<summary><b>Show the notes for the latest release</b></summary>

<!-- latest-changes-en:begin -->
**[1.17.1] - 2026-09-28 : Preview builds can now be received by those who opt in, lists and Favorites scroll at the edge while dragging, and switching from dual-pane to single-pane keeps the pane you are working in**

### Added

- **While dragging, moving the cursor to the edge of a list or Favorites now scrolls it that way (#362)** [Preview 1.17.0.1] — Lists did not scroll during a drag, so you could not drop onto a folder that was out of view. As in File Explorer, moving the cursor to the top or bottom edge of a list while dragging (in the details view, over the column headers too) now scrolls it that way, faster the closer you are to the edge; it stops when you leave the list or release the button. Even with the cursor held still, the folder row that scrolls under it is highlighted, so release there to copy or move into that folder. This works in both the details and icon views, and for drags from the other pane or from File Explorer. Favorites in the nav pane scroll the same way when you reorder or add items.

- **Preview builds let you receive changes in progress before the weekly release (#363)** [Preview 1.17.0.1] — Until now every fix went out to everyone as a new version, so on busy weeks several updates arrived in a day. From now on, the release that goes to everyone comes out once a week, and changes in between are shipped as preview builds, several times a day if needed. Only people who turn on "Also receive preview builds" under Control Deck > About > Auto-update get them (off by default). A preview build is numbered as the previous release plus a fourth part (e.g. 1.17.0.1), and preview users move up to the next release when it comes out. If you turn the option off again, you keep the preview build you have and return to release versions from the next release.

### Changed

- **After updating to a preview build, "What's New" now shows what changed at startup (#363)** [Preview 1.17.0.3] — Changes in preview builds have no version heading until they reach a release, so updating to a preview build showed no "What's New" card and you could not tell what had changed. The card now reads the mark on each changelog entry that says which preview build it shipped in, and lists only the entries that arrived in preview builds newer than the one you last saw. If you skipped a preview build, its entries are included too. The card notes that these are changes delivered early in a preview build. Changelog entries now carry the number of the preview build they first shipped in (for example [Preview 1.17.0.2]); the mark stays after the release, so the history shows which change came out early in which preview build.

- **Switching from dual-pane to single-pane now keeps the pane you are working in (#365)** [Preview 1.17.0.3] — Switching to single-pane mode always showed Pane A, so if you were working in Pane B you were moved to Pane A. The pane you were using now stays on screen. While Pane B is the one shown, Pane A is hidden, so `←`, the command palette's "Focus left pane", the `F6` focus cycle and the Tab List in the navigation pane do not move to it. In single-pane mode the Tab List shows the tabs of the pane on screen. Switching back to dual-pane restores Pane A and Pane B at the same widths as before.

> See [Releases](https://github.com/sulkyjp/zenithFiler_update/releases) for the full history.

**[1.17.1] - 2026-09-28 : 先行版を希望者だけが受け取れるようにし、ドラッグ中に一覧やお気に入りの端で自動スクロールするようにし、2 画面から 1 画面に切り替えたときにフォーカスのあるペインを残すようにした**

### Added

- **ドラッグしたまま一覧やお気に入りの端へカーソルを寄せると、その方向へ自動でスクロールするようにしました (#362)** 〔先行版 1.17.0.1〕 — これまではドラッグ中に一覧がスクロールせず、見えていないフォルダへはファイルを落とせませんでした。エクスプローラーと同じく、ドラッグしたまま一覧の上端・下端（詳細表示では列見出しの上も）へカーソルを寄せると、その方向へ流れます。端に近いほど速く、一覧の外へ出るかボタンを離すと止まります。カーソルを止めていても、流れてきたフォルダの行が強調されるので、そこで離せばそのフォルダへコピー・移動します。詳細表示とアイコン表示の両方、反対のペインやエクスプローラーからのドラッグでも同じです。ナビペインのお気に入りでも、並べ替えや登録のときに同じようにスクロールします。

- **週 1 回の製品版とは別に、開発中の変更を先に受け取れる「先行版」を用意しました (#363)** 〔先行版 1.17.0.1〕 — これまでは直すたびに全員へ新しい版を配っていて、多い週は 1 日に何本も更新が届いていました。これからは、全員に届く製品版は週 1 回にまとめます。その間の変更は、先行版として 1 日に何度でも出します。先行版を受け取るのは、Control Deck ＞ このアプリについて ＞ 自動更新 の「先行版も受け取る」をオンにした人だけです（既定はオフ）。先行版の番号は、直前の製品版に 4 桁目を足した形（例: 1.17.0.1）で、次の製品版が出ると先行版の人もそちらへ上がります。オフに戻すと、入っている先行版はそのままで、次の製品版から製品版に戻ります。

### Changed

- **先行版に上げたときも、起動後に「更新のお知らせ」で何が変わったかを見られるようにしました (#363)** 〔先行版 1.17.0.3〕 — 先行版の変更は製品版になるまで版の見出しを持たないため、先行版に上げても「更新のお知らせ」が出ず、何が変わったのかが分かりませんでした。いまは、変更履歴の各項目に付いた「どの先行版で出たか」の印を見て、前に見た版より新しい先行版で入った項目だけを並べます。先行版を 1 つ飛ばして上げた場合は、飛ばした版の項目もまとめて出ます。カードの上には、先行版で先に届いた変更であることを添えます。変更履歴（CHANGELOG）の項目には、先に出した先行版の番号（例〔先行版 1.17.0.2〕）を書くようにしました。製品版になったあとも残るので、どの変更をどの先行版で先に出したかが履歴から分かります。

- **2 画面から 1 画面に切り替えたとき、フォーカスのあるペインを残すようにしました (#365)** 〔先行版 1.17.0.3〕 — これまでは 1 画面にすると必ず A ペインが表示され、B ペインで作業していても A に切り替わっていました。いまは、そのとき操作していたペインをそのまま 1 画面で表示します。B を残しているときは A が隠れるので、`←` や コマンドパレットの「左のペインへ」、`F6` のフォーカスの巡回、ナビペインのタブ一覧は、隠れている A へは移りません。タブ一覧は、1 画面では表示しているペインのタブを並べます。2 画面に戻すと、A と B は切り替える前と同じ幅で並びます。

> 過去の変更履歴は [Releases](https://github.com/sulkyjp/zenithFiler_update/releases) を参照してください。
