## Latest Changes — [1.14.18] - 2026-09-16 : Fixed a crash from arrow keys in single-pane mode, and added combined Properties for multiple files and opening URLs from the address bar

### Added
- **Feedback history now lets you answer "It's fixed" or "Still happening" in one click on reports the developer has fixed (#315)** — until now, after reading a reply saying something was fixed, the only way to say it wasn't was to write a reply, and whether the fix actually worked never reached the developer. When the developer's reply names the version with the fix, confirmation buttons appear in the expanded row once your app is on that version or later, and an accent bar marks the row. "Still happening" also sends anything typed in the reply box and puts the report back in progress. You're only asked once per fix
- **Hovering an internet shortcut (.url) now shows its URL (#316)** — just like a shortcut's (.lnk) target, resting the mouse on a .url file in detail or icon view shows its URL in a tooltip. The URL is read in the background after the list loads, so it may appear a moment after the list itself

### Changed
- **The command palette ("find and run any action by name") now closes when you click outside it (#320)** — while the palette is open the main window doesn't accept input, so clicking it didn't close the palette, and Esc was the only way to close it without running anything. Clicking outside the palette now closes it without running anything. A click right after it opens (such as the second click of a double-click on the ≡ button) and clicks on IME candidate lists don't close it. Quick Jump and the challenge history, which also close on an outside click, could close when you clicked near their lower-right corner at display scaling other than 100%; that's fixed too

### Fixed
- **Fixed the app closing when arrow keys are pressed in single-pane mode (#318)** — in single-pane mode, pressing → in the file list (or Tab or F6) switched the target to the B pane, which isn't on screen. Pressing an arrow key after that made the step that hands keys to the B pane's list call itself over and over, and the app closed without any error message. Single-pane mode no longer switches to the B pane, and switching from two panes to one while the B pane is active moves you back to the A pane. Keys are also never handed to a list that isn't on screen
- **Fixed Properties being unavailable when several files are selected (#317)** — with several items selected, the right-click menu had no Properties entry and Alt+Enter showed only the first item. Selecting two or more items now opens one combined Properties sheet, so you can check their total size or change attributes for all of them at once. It works the same from the right-click menu, Alt+Enter, and the Windows menu shown with Shift+right-click. If the selection includes items from places that can't be combined, such as phones or FTP/SFTP sites, you're told so instead
- **Fixed the Manual and Version History window's title bar ignoring the theme (#319)** — this was the only window whose title bar was drawn by Windows, so it kept the Windows colors whatever the app theme was, leaving a light title bar above dark content in a dark theme. The title bar is now drawn in the theme's colors like the Settings window, and it follows theme changes while the window is open. The × button inside the window, which duplicated the title bar's close button, has been removed
- **Fixed nothing happening when a URL is typed into the address bar (#316)** — everything typed into the address bar was checked as a folder, so a URL starting with `https://` was silently dropped as a missing folder and no error was shown. Typing an http or https URL and pressing Enter now opens it in your default browser, the same as opening an internet shortcut (.url). It isn't added to history, and the address bar goes back to showing the current folder. Also, cancelling the "Add site" dialog that appears for a server address typed into the address bar no longer leaves the typed text in the address bar

> See [Releases](https://github.com/sulkyjp/zenithFiler_update/releases) for the full history.

## 最新の変更履歴 — [1.14.18] - 2026-09-16 : 1 分割で矢印キーを押すと落ちる問題を直し、複数選択のプロパティとアドレスバーの URL を開けるようにした

### Added
- **フィードバック履歴で、作者が直した報告に「直った／まだ直っていない」をワンタップで返せるようにした (#315)** — これまでは修正の回答を読んでも、直っていなかったと伝えるには返信を書くしかなく、直ったかどうかは作者に届かないままだった。作者が修正したバージョンを添えて回答した報告では、お使いのアプリがそのバージョン以上になると、行を開いた先に確認のボタンが出る（行の左端にもアクセントバーが出る）。「まだ直っていない」は返信欄に書いた説明も一緒に送り、報告は対応中に戻る。同じ修正について尋ねるのは一度だけ
- **インターネットショートカット（.url）にマウスを乗せると、URL を表示するようにした (#316)** — ショートカット（.lnk）のリンク先と同じく、詳細ビュー・アイコンビューのどちらでも .url にマウスを止めると URL がツールチップで出る。URL は一覧を表示したあとに裏側で読むので、表示直後は少し遅れて出ることがある

### Changed
- **「すべての操作を名前で探して実行」（コマンドパレット）を、外側をクリックして閉じられるようにした (#320)** — パレットを開いている間は本体が操作を受け付けないため、本体を押してもパレットは閉じず、何も実行せずに閉じるには Esc を押すしかなかった。パレットの外をクリックすると、何も実行せずに閉じる。開いた直後の押下（≡ ボタンのダブルクリックの 2 回目など）や、日本語入力の変換候補のクリックでは閉じない。あわせて、同じく外側のクリックで閉じるクイックジャンプとチャレンジの履歴で、表示倍率が 100% 以外のときにウィンドウの右下あたりを押しても閉じてしまうことがあったのを直した

### Fixed
- **1 分割で矢印キーを押すとアプリが落ちる問題を修正 (#318)** — 1 分割のとき、一覧で → を押す（Tab や F6 でも同じ）と、画面に出ていない B ペインが操作の対象に切り替わっていた。その状態で矢印キーを押すと、見えない B ペインの一覧へキーを渡す処理が自分自身を呼び続け、エラーの表示もなくアプリが終了していた。1 分割のときは B ペインへ切り替えないようにし、2 分割で B ペインを使っていた状態から 1 分割にしたときは A ペインへ戻す。見えない一覧へキーを渡すこと自体もしないようにした
- **複数のファイルを選んだとき、プロパティを表示できない問題を修正 (#317)** — 複数選んで右クリックしても「プロパティ」が出ず、Alt+Enter でも最初の 1 件分しか表示されなかった。2 件以上を選んでいるときは、選んだ項目をまとめたプロパティを 1 枚で表示するようにしたので、合計サイズの確認や属性のまとめての変更ができる。右クリックメニュー・Alt+Enter・Shift+右クリックで出る Windows のメニューのどれから開いても同じ。スマホや FTP/SFTP など、まとめて表示できない場所の項目が混ざっているときは、その旨を知らせる
- **マニュアル・更新履歴のウィンドウで、タイトルバーにテーマの色が付かない問題を修正 (#319)** — このウィンドウだけタイトルバーを Windows が描いていたため、アプリのテーマに関係なく Windows の色のまま残り、ダークテーマでは暗い本文の上に明るいタイトルバーが乗っていた。設定画面と同じく、タイトルバーもテーマの色で描くようにし、開いたままテーマを切り替えても追随する。タイトルバーの閉じるボタンと二重になるので、ウィンドウの中にあった × ボタンは外した
- **アドレスバーに URL を入力しても何も起きない問題を修正 (#316)** — アドレスバーの入力はすべてフォルダとして存在を確かめていたため、`https://` で始まる URL は「フォルダが無い」として黙って捨てられ、エラーも出なかった。http / https の URL を入力して Enter を押すと、インターネットショートカット（.url）を開いたときと同じく既定のブラウザで開くようにした。履歴には積まず、アドレスバーの表示は今いるフォルダに戻る。あわせて、アドレスバーに打ったサーバーのアドレスで出る「接続先の追加」を取り消したときも、打ち込んだ文字がアドレスバーに残らないようにした
