    Privacy Policy¶

    This page explains what Zenith Filer sends over the internet, when, and how to turn it off. Zenith Filer is made by one developer (sulkyjp).

    In short:

    • Zenith Filer has no analytics, no telemetry and no crash reporting. Your files, folder names and usage history stay on your PC.
    • A few features talk to servers: the update check, the XP leaderboard, the theme and Stickman stores, and feedback. Each one is described below, with how to turn it off.
    • AI features send data only to the AI service you set up, and only after you have entered an API key or chosen a local model. With no AI set up, nothing is sent.
    • Your Pro license is checked on your PC. The license key is never sent anywhere.

    What stays on your PC¶

    Settings, favorites, history, usage statistics, the search index, logs and your license file are all stored in the folder next to ZenithFiler.exe. None of them are uploaded unless you attach part of the log to feedback yourself (see Feedback).

    What the app sends, and when¶

    Update check¶

    • What is sent: a request for the latest version number. The request carries the app's version (as the User-Agent) and, if you receive preview builds, that you want the preview channel. Nothing else.
    • Where: the developer's update server (on Cloudflare). If it does not answer, GitHub's release API is used instead.
    • When: 30 seconds after start, then every 4 hours.
    • Turn off: Control Deck › About › Auto Update.

    XP leaderboard¶

    The app can post your experience points to an online leaderboard that other users can see.

    • What is sent: a random ID created for this installation (see Identifiers), a display name, your title (a nickname based on your achievements), XP and level.
    • Off until you turn it on: a new installation does not upload anything to the leaderboard. (Installations from before this change upload anonymously unless they were turned off.)
    • Display name: with "Upload anonymously" the display name is a fixed "Anonymous Adventurer" (in the app's language). With "Upload", the name you entered for the leaderboard is used (or your store user name if that is empty).
    • When: at most once every 20 hours when the app starts, and when you level up.
    • Stored: yes, on the developer's server: the ID, display name, title, XP, level and the time of the last upload. IP addresses are not stored.
    • Turn on or off: Control Deck › Challenges. Delete your entry: "Remove from ranking" on the same page.

    Theme store and Stickman store¶

    • Browsing: the theme list and theme files are downloaded from GitHub and the developer's server. When you open the theme settings or a store page, the installation ID is sent so the app can show the ratings you gave and the items you uploaded.
    • Rating, uploading and deleting: only when you do it. A rating sends the installation ID, the item name and the score. An upload sends the installation ID and the theme or Stickman file as it is, including the author name and description written in it.
    • Stored: uploads and ratings are kept on the developer's server and shown to other users. You can delete your own uploads from the store.

    Feedback¶

    Feedback you send from Control Deck › Feedback is posted as an issue in the developer's private GitHub repository. Only the developer can read it.

    • Always sent: your category, title and message.
    • Only if you tick the box (both are off by default, and you see a preview before sending):
    • "Attach system information": app version, Windows version, .NET version, CPU architecture, the app's memory use, screen size, DPI scaling and the current theme name.
    • "Attach recent error log": up to five recent warning or error lines from the app's log, each with three lines before it. These lines can contain folder paths. Your Windows user name in those paths is replaced with <user> before you see the preview, but other folder and file names stay as they are. Check the preview and untick the box if you do not want to share them.
    • Replies: when you open the Feedback page, the app reads the developer's replies to the feedback you sent from this PC. Replies you write are posted the same way, with the app version.

    AI features¶

    AI features are optional. Data is sent only to the service you choose in Control Deck › AI, and only after you have set one up (an API key for Claude, OpenAI, Azure OpenAI or Gemini, or a local model with Ollama or Claude Code).

    • What is sent: the text needed for the task. Depending on the feature this includes folder paths, file and folder names, sizes and dates, the names, paths and descriptions of your favorites, search keywords, or text you type. File contents are not sent by the built-in features; a macro you write can send whatever text it passes to the AI.
    • Features that run on their own once AI is set up (each can be switched off in the list of automatic features on Control Deck › AI):
    • Rename suggestions, when the rename dialog opens (folder path and nearby names)
    • Backup AI Summary, when a settings backup is made at start-up (the changed settings, which can include folder paths such as your favorites). Off at first on new installations
    • Achievement titles and backstories, when your achievements change (achievement names only)
    • Off by default: the start-up greeting and the description for new favorites.
    • Fully local: with Ollama on this PC, nothing leaves your computer.
    • The AI service handles the data under its own privacy policy. Note that Gemini's API receives the key as part of the request address; this is how Google's API works.

    Connections you set up¶

    FTP / FTPS / SFTP servers, Box, and an Ollama server on another computer are contacted only because you added them. The app sends what is needed to sign in and to list, read or write the files you work with.

    Downloads you start¶

    Installing Ollama or FFmpeg from the settings downloads them from their official sources (ollama.com and GitHub).

    Identifiers¶

    • When the app first starts, it creates a random installation ID. It is not derived from your name, your PC or your hardware. It is used only by the leaderboard and the stores, so that your entries, ratings and uploads stay linked to you.
    • The license file records a Windows machine ID so that the license works on this PC. It stays on your PC and is never sent.
    • The app does not read or send your Windows user name or computer name.

    How secrets are stored¶

    API keys, Box sign-in tokens and FTP/SFTP passwords are encrypted with Windows' data protection (DPAPI) for your Windows account before they are saved. They are sent only to the service they belong to.

    Purchases¶

    Pro is sold through Polar (outside Japan) and Vector (in Japan). Payment and your e-mail address are handled by them under their own privacy policies. The app itself does not contact either of them; the license key you enter is checked on your PC.

    Services involved¶

    Service Used for
    GitHub Releases, update fallback, theme and Stickman files, feedback
    Cloudflare The developer's server for updates, leaderboard and stores
    The AI service you choose AI features
    Polar / Vector Purchases

    Deleting your data¶

    • Leaderboard entry: Control Deck › Challenges › "Remove from ranking".
    • Themes and Stickman behaviors you uploaded: delete them from the store.
    • Ratings and feedback: ask through GitHub Issues or Control Deck › Feedback.
    • Everything on your PC: delete the Zenith Filer folder.

    Changes and contact¶

    When what the app sends changes, this page is updated together with the app. Questions: GitHub Issues or Control Deck › Feedback.
