    キーボードショートカット一覧¶

    設定 → ショートカットキー から、キーの体系（プリセット）を選べます。どれを選んでも 1 つ 1 つのキーは個別に変更できます。

    キーの体系を選ぶ¶

    プリセット 性格
    Zenith 標準 1 つのキーに 1 つの機能。 従来からの割り当てです。以前のバージョンから使っている場合はこれになります
    Zenith 2（2 打鍵） Ctrl+K に続けて 1 打鍵でビューを開き、Ctrl+B でペインと配置を操ります。押したまま少し待つと次に押せるキーの一覧が出るので、覚えていなくても使えます。新しくインストールした場合の既定です
    エクスプローラー風 Backspace で戻る、Alt+↑ で上へ。Windows のエクスプローラーと同じ指の運びになります
    Total Commander 風 F5 でコピー、F6 で移動、F8 で削除。ファンクションキー中心の操作系です

    体系を切り替えても、ご自身で変更したキーはそのまま残ります。

    Zenith 標準のキー一覧¶

    キー 動作
    Tab AペインとBペインのフォーカスを切り替え（Zenith 2 では、画面の要素を順に辿る本来の働きに戻ります）
    F6 / Shift + F6 枠を順に巡ってフォーカスを移す: ナビ左上 → ナビ左下 → A ペイン → B ペイン → ナビ右上 → ナビ右下。閉じている枠と、1 画面モードで隠れている B ペインは飛ばします。ターミナルからもこのキーで抜けられます
    ← Bペインにフォーカスがあるとき、Aペインへ切り替え（アイコンビューでは選択の左移動になります）
    → Aペインにフォーカスがあるとき、Bペインへ切り替え（2ペイン表示時。アイコンビューでは選択の右移動になります）
    Ctrl + ホイール ファイル一覧の上で、アイコンの大きさを無段階に変更（一覧ビューとの行き来もこのキーで行えます）
    Ctrl + Tab 次のタブへ切り替え
    Ctrl + T 新しいタブを開く
    Ctrl + W 現在のタブを閉じる
    Space Quick Preview: 選択中のファイルの中身をオーバーレイ表示（テキスト系・画像・PDF・HTML・Excel/CSV・Office 文書に対応。再度 Space または Esc で閉じる）
    ← / → (プレビュー中) Quick Preview 表示中に前後のファイルへ切り替え（ディレクトリはスキップ、リスト端で停止）
    Enter フォルダを開く / ファイルを実行 / フォルダショートカット（.lnk）はリンク先フォルダを新しいタブで開く
    Backspace 上の階層へ移動
    Alt + ← 前のフォルダに戻る
    Alt + → 次のフォルダに進む
    F2 名前の変更
    Shift + F2 一括リネーム: 選択したアイテムの名前をルールに沿ってまとめて変更（一括リネーム）
    Ctrl + Shift + N 新規フォルダを作成（作成後にフォーカスし、名前の変更可能な状態になる）
    F5 フォルダ内容の更新
    Ctrl + C コピー
    Ctrl + X 切り取り
    Ctrl + V 貼り付け
    Ctrl + Z 元に戻す（リネーム、移動、コピー、新規作成など）
    Delete 削除（ごみ箱へ）
    Ctrl + Shift + E アプリの表示/非表示をトグル（グローバルホットキー）: 最前面に表示中なら隠す（常駐モードONならトレイへ格納してタスクバーから消す／OFFなら最小化）、隠れている・最小化・背面のときは前面化してアクティブなファイルペインにフォーカスする。このキーだけは Windows 全体に登録するため、常駐ツールなど他のアプリが先に同じキーを使っていると登録できません。その場合は Control Deck →「ショートカットキー」に警告が出るので、空いているキーへ変更してください
    Ctrl + Shift + X 現在のフォルダを Windows 標準のエクスプローラーで開く
    Ctrl + Shift + 1 サイドバーを「お気に入り」に切り替え
    Ctrl + Shift + 2 サイドバーを「ツリービュー」に切り替え
    Ctrl + Shift + 3 サイドバーを「参照履歴」に切り替え
    Ctrl + Shift + 4 サイドバーを「インデックス検索設定」に切り替え
    Ctrl + Shift + 5 サイドバーを「ワーキングセット」に切り替え
    Esc (検索バー内) 多段リセット: 1回目はキーワード消去、2回目はサイズ・日付・スコープのフィルタも全消去して検索解除
    Ctrl + F アクティブなペインの検索バーにフォーカス（インデックス検索モード中は通常モードに戻る）
    Ctrl + Shift + F 検索バーにフォーカスし、インデックス検索モードに入る
    Ctrl + Shift + G ファイル内容検索（grep）モードに切り替え
    Ctrl + I 表示中のフォルダをその場で絞り込む（検索バーの Filter モードに入る）
    Ctrl + Shift + Q 1画面モード（Aペインのみ）に切り替え
    Ctrl + Shift + W 2画面モード（Aペイン＋Bペイン）に切り替え
    Ctrl + Shift + ` 1画面モード⇔2画面モードをトグル切替
    Ctrl + Shift + [ 左ナビペインの表示/非表示を切り替え
    Ctrl + Shift + ] 右ナビペインの表示/非表示を切り替え
    Ctrl + Shift + 6 サイドバーを「最近開いたフォルダ」に切り替え
    Ctrl + Shift + 7 サイドバーを「最近開いたファイル」に切り替え
    Ctrl + Shift + 8 サイドバーを「プロパティ」に切り替え
    Ctrl + Shift + D タブを複製
    Ctrl + N 現在のタブと同じフォルダーを反対ペインに複製（1画面のときは2画面に切り替え）
    Ctrl + L アドレスバーにフォーカス
    Ctrl + Shift + A タブ一覧を表示
    Ctrl + Shift + Tab 前のタブへ切り替え
    Ctrl + P クイックジャンプ
    Ctrl + 3 上下2画面モードに切り替え
    Ctrl + A 全選択
    A〜Z / 0〜9 インクリメンタルサーチ: 詳細ビューで押したキーで始まるファイル/フォルダへ選択を移動。同じキーを連打すると同頭文字の次の候補へサイクル。500ms 以内に異なるキーを続けると先頭文字列で絞り込みジャンプ（Ctrl / Alt との組み合わせは除く）
    Ctrl + Alt + F4 常駐モードで完全終了
    Esc パンくずのドロップダウンメニューを閉じる／更新履歴・マニュアルなどのサブウィンドウを閉じる

    Zenith 2 の 2 打鍵キー¶

    Ctrl+K か Ctrl+B を押し、指を離さずに続けてもう 1 打鍵します（Ctrl は離しても構いません）。押したまま少し待つと、次に押せるキーの一覧が画面下に出ます。覚えている場合は続けて打てば一覧は出ません。一覧はクリックでも実行できます。Esc か 2 秒の放置で取り消せます。

    Ctrl + K — ビューを開く（開くと同時にフォーカスが移り、もう一度同じキーでファイル一覧へ戻ります）

    キー ビュー キー ビュー
    F お気に入り M マクロ
    T ツリー N 接続先
    H 履歴 C ターミナル
    Shift + H 検索履歴 Shift + C ターミナル 2
    I インデックス検索 L タブ管理
    S 検索プリセット Shift + L AI タブ管理
    W ワーキングセット O AI フォルダ整理
    R 最近開いたファイル / AI マニュアル
    Shift + R よく使うフォルダ P プロパティ
    D ドライブ V プレビュー

    Ctrl + B — ペインと配置

    キー 動作 キー 動作
    1 / 2 / 3 1 画面 / 左右 2 画面 / 上下 2 画面 L ウィンドウ配置のプリセット
    Z 1 画面 ⇔ 2 画面をトグル N ナビペインの配置
    [ / ] 左 / 右のナビペインを開閉 W ワーキングセットのクイックアクセス
    C 選択を反対のペインへコピー M 選択を反対のペインへ移動

    Zenith 2 では、サイドバー切替の Ctrl+Shift+1〜8 と、ペイン操作の Ctrl+Shift+Q/W/`/[/]/L/J/S は上の 2 つに置き換わります。Tab はペイン切替から解放され、画面の要素を順に辿る本来の働きに戻ります（ペインの移動は ← →）。

    ナビペインの中で使うキー（全ビュー共通）¶

    ナビペインのどのビューでも、同じキーが同じ意味で働きます。そのビューに該当する操作が無いキーは、押しても何も起きません（別の意味に化けることはありません）。

    キー 意味
    ↑ ↓ 行を選ぶ
    Enter その行を使う（フォルダなら開く・セットなら適用・マクロなら実行・接続先なら接続）
    Esc ファイル一覧へ戻る（ビューは開いたまま）
    ビューを開いたときと同じキー 同じくファイル一覧へ戻る
    F2 名前の変更（対応するビューのみ）
    Delete 削除・登録解除（対応するビューのみ）
    Insert 追加・保存（対応するビューのみ）
    Ctrl + F そのビューの中で絞り込み（絞り込み欄のあるビューのみ）

    一覧を持たないビュー（プレビュー・プロパティ・マクロ・AI 系）でも、Esc でファイル一覧へ戻れます。ターミナルの中だけは例外で、アプリはキーを一切横取りしません（F6 が唯一の出口です）。

    ショートカットキーを教えてもらう¶

    ツールバーやステータスバーのボタンをマウスで押したとき、その操作にキーが割り当てられていれば「『2画面に切替』は Ctrl+Shift+W でも実行できます」と通知でお知らせします。同じ操作につき 3 回までで、以降は黙ります。キーボードで実行したときは出ません。設定 →「ショートカットキー」の一番上で止められます。
