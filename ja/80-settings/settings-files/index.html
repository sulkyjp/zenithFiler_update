    設定ファイル構造¶

    settings.json¶

    セクション別の主要プロパティ。

    セクション 代表プロパティ
    ウィンドウ配置 WindowLeft, WindowTop, WindowWidth, WindowHeight, WindowState, PaneCount, PaneWidthRatio, PaneSplit
    基本設定 SingleClickOpenFolder, ConfirmDelete, RestoreTabsOnStartup, NotificationDurationMs, ResidentMode
    表示 ShowPathInTitleBar, ShowFileExtensions, ShowHiddenFiles, ListRowHeight
    検索デフォルト DefaultGroupFoldersFirst, DefaultSortProperty, DefaultSortDirection
    インデックス IdleOnlyExecution, IdleCpuThreshold, NetworkDriveSlowIndex, FullRebuildMinInterval, IndexScheduleDto
    演出（Effects） ShowStartupEffects, ShowGlowBar, ShowScanBar, ShowTabEffects, ShowPaneTransitions, ShowThemeEffects, ShowStatusBarEffects, ShowPreviewEffects, ShowListEffects, ShowNavPaneEffects, ShowControlDeckEffects, ShowDragEffects
    ショートカット CustomKeyBindings（List<KeyBindingDto>?）
    アップデート AutoUpdateEnabled, LastUpdateCheck, SkippedVersions
    AI AiProvider, AiModel, AzureEndpoint（ApiKey は DPAPI 暗号化で別保存）

    テーマ JSON（themes/*.json）¶

    • Category: Standard / WarmCozy / Professional / Premium / RetroTech のいずれか。未指定時はアプリ内の既定の分類が使われる。
    • Description / Author: カードに表示されるメタ情報。
    • カラーキー: 130 キー（テーマ（配色カスタマイズ） 参照）。カスタマイズ差分は themes/_custom/{テーマ名}.json に保存。
    • アプリが知らないカラーキーは、読み込み時に無視される。

    言語 JSON（lang/*.json）¶

    • 10 言語（ja・en・de・es・fr・ko-KR・pt・ru・zh-CN・zh-TW）
    • 独自の言語を足すときは、同じキーを持つ .json をこのフォルダに置くと自動で認識される

    Stickman 行動 JSON（stickman/*.json, stickman/rewards/*.json）¶

    • 構文仕様は JSON 行動定義リファレンス 参照
    • unlock フィールドで実績解放連動（報酬行動パターン）
    • description は単一文字列または {locale: text} マップ（10 言語対応）
