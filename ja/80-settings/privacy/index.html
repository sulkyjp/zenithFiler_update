    プライバシーポリシー¶

    Zenith Filer がインターネットに何を、いつ送るのか、どうすれば止められるのかをまとめたページです。Zenith Filer は個人の開発者（sulkyjp）が作っています。

    要点:

    • Zenith Filer は利用状況の収集（アナリティクス・テレメトリ）も、クラッシュの自動送信もしません。ファイル、フォルダ名、使った履歴は PC の中に残ります。
    • サーバーとやり取りする機能は、更新の確認・経験値のランキング・テーマとスティックマンのストア・フィードバックです。それぞれ何を送り、どう止めるかを下に書いています。
    • AI の機能は、あなたが設定した AI のサービスにだけ送ります。API キーを入れるかローカルのモデルを選ぶまでは、何も送りません。
    • Pro のライセンスは PC の中で確かめます。ライセンスキーをどこかへ送ることはありません。

    PC の中に残るもの¶

    設定・お気に入り・履歴・利用統計・検索のインデックス・ログ・ライセンスのファイルは、すべて ZenithFiler.exe の隣のフォルダに保存します。フィードバックにログの一部をご自分で添付したとき（フィードバック）を除いて、外へ送ることはありません。

    送るもの・送るとき¶

    更新の確認¶

    • 送るもの: 最新版の番号の問い合わせ。アプリの版（User-Agent として）と、先行版を受け取る設定ならそのこと。ほかには何も送りません。
    • 送り先: 開発者の更新サーバー（Cloudflare 上）。応答が無いときは GitHub のリリースの API。
    • いつ: 起動の 30 秒後と、その後 4 時間ごと。
    • 止め方: Control Deck ＞ このアプリについて ＞ 自動更新。

    経験値のランキング¶

    経験値を、ほかの利用者も見られるオンラインのランキングに送れます。

    • 送るもの: このインストールのために作った無作為の ID（識別子）、表示名、二つ名（実績から付く呼び名）、経験値、レベル。
    • オンにするまで送りません: 新しく入れた Zenith Filer は、ランキングへ何も送りません。（この変更より前から使っている方は、オフにしていなければ匿名で送ります。）
    • 表示名: 「匿名でアップロードする」では、表示名は決まった「匿名の冒険者」（アプリの表示言語の言い方）になります。「アップロードする」では、ランキング用に入れた名前を使います（空ならストアのユーザー名）。
    • いつ: 起動したとき（20 時間に 1 回まで）と、レベルが上がったとき。
    • 保存: あり。開発者のサーバーに ID・表示名・二つ名・経験値・レベル・最後に送った日時を保存します。IP アドレスは保存しません。
    • オン・オフ: Control Deck ＞ チャレンジ。登録を消す: 同じページの「ランキングから削除」。

    テーマストアとスティックマンストア¶

    • 見るとき: テーマの一覧とファイルは GitHub と開発者のサーバーから取得します。テーマの設定やストアのページを開くと、自分が付けた評価と自分がアップロードしたものを出すために、インストールの ID を送ります。
    • 評価・アップロード・削除: 操作したときだけ。評価ではインストールの ID・対象の名前・点数を送ります。アップロードではインストールの ID と、テーマやスティックマンのファイルをそのまま送ります（ファイルに書かれた作者名や説明も含みます）。
    • 保存: アップロードと評価は開発者のサーバーに保存し、ほかの利用者にも表示します。自分のアップロードはストアから削除できます。

    フィードバック¶

    Control Deck ＞ フィードバック から送った内容は、開発者の非公開の GitHub リポジトリに Issue として登録します。読めるのは開発者だけです。

    • 必ず送るもの: 種類・件名・本文。
    • チェックを入れたときだけ送るもの（どちらもはじめはオフで、送る前に内容を確認できます）:
    • 「システム情報を添付」: アプリの版、Windows の版、.NET の版、CPU の種類、アプリのメモリ使用量、画面の大きさ、表示の拡大率、いまのテーマ名。
    • 「直近のエラーログを添付」: アプリのログから、最近の警告・エラーの行を 5 件まで（それぞれ直前の 3 行と一緒に）。ログの行にはフォルダのパスが入ることがあります。パスの中の Windows のユーザー名は、確認画面に出す前に <user> に置き換えますが、ほかのフォルダやファイルの名前はそのままです。確認画面を見て、送りたくないときはチェックを外してください。
    • 返信: フィードバックのページを開くと、この PC から送ったフィードバックへの開発者の返信を読み込みます。あなたが書いた返信も同じ形で送ります（アプリの版を添えます）。

    AI の機能¶

    AI の機能は使わなくてもかまいません。送り先は Control Deck ＞ 生成AI で選んだサービスだけで、設定を済ませるまで（Claude・OpenAI・Azure OpenAI・Gemini の API キーを入れるか、Ollama や Claude Code のローカルのモデルを選ぶまで）は何も送りません。

    • 送るもの: その機能に要る文字だけ。機能によって、フォルダのパス、ファイルやフォルダの名前・大きさ・日時、お気に入りの名前・パス・説明、検索した言葉、あなたが入力した文などです。組み込みの機能はファイルの中身を送りません。ご自分で作ったマクロは、AI に渡すと書いた文をそのまま送ります。
    • 設定を済ませると自動で動くもの（Control Deck ＞ 生成AI の自動機能の一覧で、それぞれ止められます）:
    • 名前の変更の候補: 名前の変更の画面を開いたとき（フォルダのパスと周りの名前）
    • バックアップ AI サマリー: 起動時に設定のバックアップを作ったとき（変わった設定。お気に入りなどのフォルダのパスを含むことがあります）。新しく入れたときはオフです
    • 二つ名と由来: 実績が増えたとき（実績の名前だけ）
    • はじめはオフのもの: 起動時のあいさつ、お気に入りに追加するときの説明。
    • 完全にローカル: この PC の Ollama を使うときは、PC の外へ何も出ません。
    • 送ったデータは、それぞれの AI のサービスが自分のプライバシーポリシーに沿って扱います。Gemini の API は、キーを問い合わせのアドレスに含めて受け取る作りです（Google の API の仕様です）。

    ご自分で設定した接続先¶

    FTP / FTPS / SFTP のサーバー、Box、別の PC の Ollama のサーバーには、あなたが登録したので接続します。ログインと、扱うファイルの一覧・読み書きに要るものを送ります。

    ご自分で始めるダウンロード¶

    設定から Ollama や FFmpeg を入れると、それぞれの公式の配布元（ollama.com と GitHub）から取得します。

    識別子¶

    • はじめて起動したときに、無作為のインストール ID を作ります。名前・PC・機器の情報から作るものではありません。ランキングとストアで、あなたの登録・評価・アップロードを結び付けるためだけに使います。
    • ライセンスのファイルには、この PC でライセンスを使えるようにするため Windows の機器 ID を記録します。PC の中に残り、送ることはありません。
    • Windows のユーザー名やコンピューター名を読み取って送ることはありません。

    秘密の情報の保存¶

    API キー、Box のログイン情報、FTP / SFTP のパスワードは、保存する前に Windows のデータ保護（DPAPI）で、あなたの Windows アカウント用に暗号化します。送るのは、それぞれの持ち主のサービスにだけです。

    購入¶

    Pro は Polar（日本の外）と Vector（日本）で販売しています。支払いとメールアドレスは、それぞれのサービスが自分のプライバシーポリシーに沿って扱います。アプリはどちらにも接続しません。入力したライセンスキーは PC の中で確かめます。

    関わるサービス¶

    サービス 使うところ
    GitHub リリース、更新の確認の予備、テーマとスティックマンのファイル、フィードバック
    Cloudflare 更新・ランキング・ストアのための開発者のサーバー
    あなたが選んだ AI のサービス AI の機能
    Polar / Vector 購入

    データを消すには¶

    • ランキングの登録: Control Deck ＞ チャレンジ ＞「ランキングから削除」。
    • アップロードしたテーマやスティックマンの動き: ストアから削除します。
    • 評価とフィードバック: GitHub Issues か Control Deck ＞ フィードバック からご連絡ください。
    • PC の中のすべて: Zenith Filer のフォルダを消します。

    変更と連絡先¶

    送るものが変わったときは、アプリと一緒にこのページを更新します。お問い合わせは GitHub Issues か Control Deck ＞ フィードバック へどうぞ。
