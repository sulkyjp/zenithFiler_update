    テーマの色キー一覧¶

    テーマの JSON に書ける色の項目（キー）の全部と、それぞれが画面のどこに使われるかの一覧です。自分でテーマのファイルを作るときは テーマのファイルを自分で作る と合わせて使ってください。説明はテーマのカスタマイズ画面に出るものと同じです。

    ファイルの形¶

    • 一番外側に Description.ja（カードに出る説明。言語ごとに Description.en など）・Author（作者）・Category（テーマ一覧のどのカテゴリに並ぶか。Standard / WarmCozy / Professional / Premium / RetroTech のどれか）を置きます。
    • Chrome に "Neutral" と書くと、色では消せない見た目の癖（一覧の罫線と選択の枠・タイトルバーとツールバーの光の線と影・選択タブの強調など）を消し、エクスプローラーに近い素の見た目にします（既定のテーマ Plain が使っています）。書かなければ今までどおりです。
    • 色は 7 つのセクション Base / List / Search / Accent / ContextMenu / NavPane / Misc の中に書きます。キーは下の表のセクションに書いてください。 別のセクションに書いたキーは、名前を間違えたときと同じく黙って無視されます。
    • 色は #RRGGBB、透明度付きの #AARRGGBB（先頭の 2 桁が不透明度）、White のような色の名前で書けます。
    • 書かなかったキーは、表の「書かないとき」に従います。「＝ 〇〇」とあるキーは、そのキーと同じ色になります（親の色を変えれば、書いていない子も一緒に変わります）。色が書いてあるキーは、その色になります。
    • // で始まる行コメントを書けます。
    • 文字が背景に溶け込んで読めなくなる組み合わせは、一部の文字の色を読める明るさまで自動で寄せます。
    • どのキーがどこの色かを画面で確かめるには、テーマのカスタマイズ画面で項目を押します。使われている場所が光ります（テーマカスタマイズの自動ナビゲーション）。

    例: 一覧の交互の行の色¶

    • ファイル一覧の 1 行おきの色は List セクションの ListAlternateRowColor で決めます。設定の「表示」→「ファイル一覧」の「一覧の行を交互に色分け」がオンのときに出ます。
    • 書かなければ、背景色（BackgroundColor）から控えめな色を自動で作ります。背景色と同じ色を書いたときも、書かなかったのと同じ扱いです。縞を消したいときは設定をオフにします。
    • 半透明（#AARRGGBB）で書くと、アクティブなペインの色の上にも自然に重なります。不透明の色にすると、アクティブなペインでもその色がそのまま出ます。
    "List": {
  "ListAlternateRowColor": "#1A3A6EA5"
}

    ナビペイン（左のパネル）の一覧には、今は交互の行の色がありません。

    キーは全部で 156 個です。
