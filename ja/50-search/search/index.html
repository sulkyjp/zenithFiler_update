    検索機能¶

    検索バーの左端にある 4 つのボタンで、探し方を選びます。

    ボタン 探し方 キー
    Search 通常検索。今いるフォルダとその中のサブフォルダから、名前で探します Ctrl+F（または Ctrl+E）
    Grep 内容検索。今いるフォルダの中のファイルの中身から、文字で探します Ctrl+Shift+G
    Index インデックス検索。登録しておいた複数のフォルダから、まとめて名前で探します Ctrl+Shift+F
    Filter その場の絞り込み。今の一覧を、打った文字で絞り込みます Ctrl+I

    Ctrl+F は検索欄へ移るキーで、インデックス検索の最中なら通常検索に戻します。検索欄に語を打って Enter を押すと探します。結果をどこに出すかは「検索の挙動」で選べます（検索の挙動）。

    通常検索（Search）¶

    • 対象: 今開いているフォルダと、その中のサブフォルダすべてです。その場でフォルダをたどって探します。
    • 書き方: スペースで区切ると AND（すべて含む）、| で区切ると OR（どれかを含む）、-語 で除外、ext:pdf で拡張子を指定、*.pdf・報告?.txt のワイルドカードが使えます。種類・更新日時・サイズでも絞れます（プロパティで絞る）。検索バーの「.*」をオンにすると、打った文字全体を正規表現として扱います（正規表現で探す）。
    • 結果: ファイルとフォルダの両方が出て、更新日時の新しい順に並びます。列の見出しを押すと、名前順など別の並びにできます。結果の上には種類の絞り込み（フォルダ・Excel・Word・PPT・PDF・TXT・EXE・BAT・JSON・画像・その他）と件数が出ます。
    • Windows の索引: 設定で、Windows の索引を使って中身も探せます（Windows の索引で中身も探す）。
    • 検索バー 2 段目: 設定で有効にすると、2画面（左右）のときだけ検索バーがヘッダーの 2 行目へ移り、入力欄とフィルタを横に広く使えます（表示オプション）。

    インデックス検索（Index）¶

    • 対象: ナビペインの「インデックス検索」ビューで登録したフォルダすべてです。今どのフォルダにいるかに関わらず、まとめて探せます。ビューは Ctrl+Shift+4（キーマップ「Zenith 2」では Ctrl+K に続けて I）で開きます。
    • ファイルとフォルダの両方がインデックスに入ります。拡張子のないファイル（一時ファイル・キャッシュなど）はインデックスに入れないので、インデックス検索では見つかりません（通常検索では見つかります）。.git や node_modules のような大きな作業用フォルダも飛ばします。
    • 結果: 更新日時の新しい順に、最大 500 件まで出ます。
    • 探すフォルダを絞る（スコープ）: インデックス検索のとき、検索バーにフォルダのアイコンとバッジ（例: 3/10）が出ます。押すと登録フォルダの一覧が開き、チェックで探す対象を選べます。「すべて選択」「すべて解除」でまとめて切り替えられます。絞り込み中はアイコンとバッジが強調されます。選択を変えると結果がすぐに出し直され、選択はアプリを閉じても残ります。ロックしたフォルダも選べ、ロックした時点の内容から探します。
    • インデックスを作っている間: 作り終えた分から順に検索に出ます。ステータスバーに「インデックス更新中（○ 件）...」と進み具合が出ます。

    フォルダの登録・更新のしかた・状態の見方は インデックスの設定 と インデックス検索 にあります。

    内容検索（Grep）¶

    • 目的: 今開いているフォルダの中のファイルの中身（テキスト）を、語で探します。名前ではなく中のテキストを対象にする点が通常検索と違います。
    • しくみ: アプリに入っている ripgrep で探します。
    • 大文字と小文字・正規表現: 内容検索のときだけ、検索バーに「Aa」（大文字と小文字を区別する）が出ます。「.*」をオンにすると正規表現で探します（正規表現で探す）。
    • 結果: 当たったファイルが並びます。Match 列には、最初に当たった行（行番号と文字）と、そのファイルで当たった数が出ます。
    • 制限: 調べるのは 1 ファイル 50 MB までで、結果は 1,000 ファイルまでです。バイナリのファイル、隠しファイル・隠しフォルダの中、Git の管理下で .gitignore に書かれたファイルは探しません。文字コードは UTF-8 と、BOM の付いたファイル（UTF-16 など）を見分けます。

    その場の絞り込み（Filter）¶

    • 目的: 今開いているフォルダの一覧を、打った文字でその場で絞り込みます。検索結果のタブは開かず、サブフォルダも見ません。
    • 操作: Ctrl+I を押すか、検索バーの Filter を押すと、検索欄にカーソルが入って Filter モードに入ります。打つたびに一覧が絞り込まれ、名前に打った文字を含む項目だけが残ります（大文字と小文字は区別しません）。「.*」をオンにすると、名前に正規表現が当たる項目だけが残ります。式を打っている途中で誤りがある間は、直前の絞り込みのまま一覧は動きません。
    • Filter モードの間は、サイズ・日付のフィルタと検索プリセットのボタンは使えません。
    • 解除: 検索欄の × か Esc で文字を消すと、一覧が元に戻って通常検索に戻ります。ほかのモードのボタンを押しても解除されます。

    検索履歴¶

    検索欄を押すと、これまでの検索の履歴が出ます。通常検索・内容検索・インデックス検索の履歴は 1 つの一覧にまとまっていて（最大 100 件）、各行のアイコンでどの探し方だったかが分かります。

    検索したときにプリセット・サイズフィルタ・日付フィルタを使っていた場合は、語の右に「検索プリセット: 名前」「サイズ: …」「日付: …」が出ます。プリセット名は保存してあるプリセットの条件と照らし合わせて出すので、手で同じ条件にしたときも出ます。

    履歴から選ぶと、探し方・サイズフィルタ・日付フィルタが検索したときの状態に戻り、もう一度探します。

    検索欄を空にする（Esc）¶

    検索欄で Esc を押すと、1 回目で文字を消し、2 回目でサイズ・日付のフィルタとスコープも消して検索を解除します。Control Deck →「検索」→「検索バー」の「Esc を一発で全リセット」（既定オフ）をオンにすると、1 回ですべて消します。

    サイズ・日付フィルタと検索プリセット¶

    • サイズ・日付フィルタ: 検索バーのサイズのボタンと日付のボタンで、ファイルの大きさと更新日時の範囲を絞れます。通常検索・インデックス検索・内容検索のどれにも効き、絞り込み中はボタンが選択の色で塗られます。ボタンを右クリックすると、そのフィルタだけを消します。詳しくは サイズ・日付フィルタ。
    • 検索プリセット: 検索バーの ★ で、よく使う条件を名前を付けて保存し、呼び出せます。★ を右クリックすると、検索の文字・サイズ・日付・スコープをまとめて消します。詳しくは 検索プリセット。

    プロパティで絞る¶

    検索欄に 名前:値 の形で書くと、ファイル名だけでなく種類・更新日時・サイズでも絞れます（エクスプローラーの検索と同じ考え方の書き方です）。ふつうの語・| の OR・-語 の除外・ext:・ワイルドカードと組み合わせられます。ファイル名の検索（サブフォルダまで）で効きます。

    書き方 意味
    kind:folder ／ kind:file フォルダだけ／ファイルだけ
    kind:picture・kind:video・kind:music・kind:document・kind:archive・kind:program 画像・動画・音楽・文書（Office・PDF・テキストなど）・圧縮ファイル・プログラム
    date:today・yesterday・thisweek・lastweek・thismonth・lastmonth・thisyear・lastyear 更新日時が今日・昨日・今週（日曜から）・先週・今月・先月・今年・昨年
    date:2026-10-01 ／ date:>2026-10-01 ／ date:<=2026-10-01 ／ date:2026/10/01..2026/10/03 その日・より後・その日まで・その間（両端を含む）
    size:empty・tiny・small・medium・large・huge・gigantic エクスプローラーと同じ区分（空・16 KB まで・1 MB まで・128 MB まで・1 GB まで・4 GB まで・4 GB より大きい）
    size:>10MB ／ size:<1.5KB ／ size:>=500 より大きい・より小さい・以上（単位は KB・MB・GB、無ければバイト）
    name:報告 名前に含む（ふつうの語と同じ）
    tags:旅行 タグに含む（前方一致）。Windows の索引を使うときだけ（下を参照）
    rating:4 ／ rating:>=4 評価が星 4 つ・星 4 つ以上。Windows の索引を使うときだけ
    • 日本語の名前でも書けます: 種類:画像・種類:フォルダー・更新日時:今週（日付: も可）・サイズ:中・名前:報告。
    • 例: 報告 kind:document date:thismonth（今月更新した、名前に「報告」を含む文書）／kind:music | kind:video（音楽か動画）／ext:pdf size:<1MB。
    • サイズで絞ると、フォルダは外れます（フォルダの大きさは検索のときには分からないため）。
    • 読めない値（kind:unknown など）は、ふつうの語として名前に当てます。
    • タグと評価（tags:・タグ:・rating:・評価:）は、設定の「Windows の索引で中身も探す」がオンで、探す場所が索引に入っているときだけ絞れます（エクスプローラーの検索と同じく、索引の情報で絞ります）。そうでないときは、ステータスバーに知らせを出し、タグと評価の語は飛ばして残りの語で探します（フォルダをたどる検索で 1 件ずつ中の情報を読むと、とても遅くなるため）。
    • 「.*」（正規表現）がオンの間は、この書き方も字面どおりに扱います。

    正規表現で探す¶

    検索バーの 「.」 をオンにすると、検索欄に打った文字を正規表現として扱います。通常検索・インデックス検索・その場の絞り込み（Filter）・内容検索（Grep）のどれでも使えます。「.」のオン／オフはペインごとに 1 つで、モードを切り替えてもそのままです。検索を反対のペインで開く設定のときは、押した側のオン／オフが引き継がれます。

    • 名前の検索（通常検索・インデックス検索・Filter）: 打った文字全体を 1 つの式として、拡張子込みの名前に当てます。名前のどこかに当たれば一致です（名前全体に合わせたいときは ^ と $ を付けます）。フォルダのパスには当てません。
      • 「.*」がオンの間は、空白の AND・| の OR・-語 の除外・ext: は正規表現の字面どおりに扱います（| は正規表現の「または」として働きます）。拡張子で絞るときは \.pdf$ のように書きます。
      • 大文字と小文字は区別しません。区別したいときは式の先頭に (?-i) を付けます。
      • .NET の正規表現の構文がすべて使えます（先読み・後読み・後方参照・名前付きグループ・条件分岐・\p{…} など）。
    • 内容検索（Grep）: ripgrep の正規表現で探します。後方参照・先読み・後読みを含む式は、自動で PCRE2 に切り替えて探します。大文字と小文字は「Aa」で切り替えます。.NET にしかない構文（バランシンググループ・文字クラスの差 [a-z-[aeiou]]）は使えません。
    探したいもの 式
    IMG_ と 4 桁の数字で始まる JPEG ^IMG_\d{4}\.jpe?g$
    old を含まない Excel ^(?!.*old).*\.xlsx$
    同じ数字が 2 つ続く名前 (\d)\1
    先頭が大文字の Report だけ (?-i)^Report
    ひらがなだけの名前のテキスト ^\p{IsHiragana}+\.txt$

    式に誤りがあるとき: 打っている途中から検索欄の枠が赤くなり、右側に「正規表現の誤り（○ 文字目付近）」が出ます。指すと詳しい理由が出ます。この状態で Enter を押しても検索せず、通知でそのことを知らせます。内容検索では、ripgrep が式を受け付けなかったときに「ripgrep が式を受け付けませんでした」と出て、指すと ripgrep のメッセージが出ます。

    時間の上限: 名前ごとの照合は 0.1 秒で打ち切ります。式が複雑すぎて上限に当たると、そこで検索を止めて「式が複雑すぎるため照合を打ち切りました」と出します（それまでに当たった分は残ります）。

    検索プリセットには「.」と「Aa」の状態も保存され、適用すると戻ります（検索プリセット）。検索履歴には保存されません。履歴から選んだときは、その時点の「.」で探します。

    検索の挙動（Control Deck で変更可能）¶

    Control Deck（標準: Ctrl+Shift+O）の「検索」→「検索結果の開き方」の「検索の挙動」で、検索の結果をどこに出すかを 3 つから選べます。既定は「同一ペイン・新規タブ」です。どれも Enter で探します。

    オプション 動作 向いている用途
    同一ペイン・新規タブ 同じペインに検索結果のタブを新しく開きます。結果のタブで語を打ち直して Enter を押すと、そのタブで探し直します。 検索したペイン内で完結するため、予測しやすく文脈が保てます。初心者にもおすすめの既定です。
    同一ペイン・現在タブ 今のタブに検索結果を出します。 タブを増やさずに済み、検索と通常の表示を素早く行き来できます。
    反対ペイン・新規タブ Aペインで探すとBペインに、Bペインで探すとAペインに、新しいタブで結果を出します。1画面のときは自動で2画面に切り替えます。 比較作業や上級者向け。検索結果と元の一覧を左右ペインで同時に見比べたい場合に便利です。

    どのオプションでも、検索バー右端の × を押すと検索を解除し、そのタブで探したフォルダの一覧に戻ります（タブは閉じません）。

    検索時に自動的に1画面モードに切り替える（「検索」→「検索バー」、既定オフ）をオンにすると、探したときに 1 画面に切り替えて結果を広く出します。Bペインで探したときは、検索のタブがAペインに出ます。検索を解除すると、元の 2 画面に戻ります。

    Windows の索引で中身も探す¶

    Control Deck の「検索」→「検索バー」の 「Windows の索引で中身も探す」（既定オフ）をオンにすると、通常の検索で Windows の索引（エクスプローラーの検索と同じ Windows Search）を使います。名前に加えて、中身にその語を含むファイル（テキスト・PDF・Office 文書など、Windows が中身を索引に入れている形式）も出ます。

    • 索引を使うのは、その場所が丸ごと索引に入っているとき（ドキュメント・ダウンロード・デスクトップなど。索引の範囲は Windows の「インデックスのオプション」で決まります）で、語だけを打ったときです。| の OR・ワイルドカード（* ?）・正規表現（「.*」）を使う検索と、索引に入っていない場所では、今までどおりフォルダをたどって名前で探します。
    • kind:・date:・size:・ext:・-語 の絞り込みは、索引の結果にも効きます。
    • 結果は最大 5,000 件です。索引は Windows が裏で作るので、作ったばかりのファイルはしばらく出ないことがあります。

    検索結果のパスクリック時の挙動（Control Deck で変更可能）¶

    Control Deck の「検索」→「検索結果の開き方」の「検索結果のパスクリック時の挙動」で、検索結果のパスの列を押したときの表示先を 3 つから選べます。既定は「同一ペイン・新規タブ」です。

    オプション 動作 向いている用途
    同一タブで表示 検索結果から通常の一覧に切り替え、そのパスを同じタブで表示します。 タブを増やさずに済み、検索結果から素早くフォルダへ移動できます。
    同一ペイン・新規タブ 同じペインに新しいタブを開きます。 検索結果タブを残したまま、押したパスを別のタブで開けます。検索との併用がしやすい既定です。
    反対ペイン・新規タブ Aペインの検索結果ならBペインに、Bペインの検索結果ならAペインに新しいタブで出します。1画面のときは自動で2画面に切り替えます。 比較作業や上級者向け。検索結果と開いたフォルダを左右で同時に見比べたい場合に便利です。
