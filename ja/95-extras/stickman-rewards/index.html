    報酬行動¶

    報酬行動パターン¶

    ナビゲーション実績（フォルダ移動回数）の各 Tier を達成すると、専用の Stickman 行動パターンが報酬として解放されます。

    報酬行動は stickman/rewards/ フォルダに格納されており、15 カテゴリ × 10 Tier = 150 件の行動パターンが用意されています。

    各パターンは 67 種のポーズを駆使し、高さ演出（yOffset）・後光（aura）・眷属（followers）・描画スケール（scale）を組み合わせた固有の動きを持ちます。行動定義はすべて全 10 言語にローカライズ済み（description.{locale} 方式、v0.45.0 で整備）。

    Tier × 演出要素 対応表¶

    Tier 演出特徴 followers aura scale 解放条件例（unlock フィールド）
    1〜3 基本ポーズと歩行の組合せ、シンプル 0 false 1.0 nv_100, nv_500, nv_1000 等
    4〜7 複数フェーズ、浮遊・上昇・降下などダイナミックな動き 0 false 1.0〜1.2 nv_5000〜nv_50000 レンジ
    8 眷属登場、リーダー周囲にランダム配置で追従 2 false 1.0〜1.2 高位ナビゲーション実績
    9 眷属増加、後光（Aura）発生 4 true 1.2〜1.5 上位ナビゲーション実績
    10 自然な群れ形成、最高級演出（大型スケール併用） 7 true 1.5〜2.0 最高位ナビゲーション実績

    眷属（followers）の挙動¶

    • 通常時はリーダーと同じポーズ・移動で追従しますが、特殊アクション（お辞儀・敬礼・祈り等の静止系ポーズ）ではその場にかしづいて停止します。
    • 配置はリーダー周辺にランダム分散。群れ感を保つためリーダーから一定半径内にクランプされます。
    • 描画は小型版（親より縮小）。性格による速度倍率の影響は受けません（リーダーに追従するため）。

    後光（aura）の発動¶

    • フェーズに "aura": true を指定すると、頭の周りに回転・脈動する放射線状のエフェクトが描画されます。
    • 配色は現在のテーマの AccentBrush または GlowBarBrush に準拠。
    • Tier 9 以上の報酬行動でのみ使用される想定ですが、カスタム行動からも利用可能（下位 Tier で使うと違和感が出るため推奨しません）。

    旧パターンのアーカイブ¶

    リデザイン前の報酬パターンは stickman/archive/ フォルダに保存されています。

    実績解放の仕組み¶

    • 報酬行動の JSON には unlock フィールドが設定されています（例: "unlock": "nv_100"）
    • 対応するナビゲーション実績チャレンジが未達成の場合、その行動はエンジンに登録されず選出されません
    • チャレンジを達成すると自動的に解放され、通常の行動と同様にランダムで選出されるようになります

    報酬タイルのホバープレビュー¶

    設定画面（Control Deck → Stickman）の報酬タイルにマウスカーソルを重ねると、その行動パターンのアニメーションプレビューがポップアップ表示されます。解放済み・未解放を問わず、どのような動きをするか事前に確認できます。

    報酬行動の ON/OFF 切り替え¶

    達成済みの報酬タイルの右上にはチェックボックスが表示されます。チェックボックスで報酬行動の有効/無効を個別に切り替えられます。無効にした報酬行動はエンジンの選出対象から除外されます。

    レアイベント「クマ出没」¶

    行動選出ごとに 1% の確率で発動する特別イベントです。アンロック条件なしで最初から有効、全ユーザーが偶発的に遭遇できます。

    • トリガー: 内部の行動選出タイミングで Random.NextDouble() < 0.01 が成立したとき
    • 演出:
      1. 犬がクマに変身（0.6 秒、dogBehavior: "transform_bear"）。色は現在の AccentBrush を HSV で暗く動的生成、体型は 1.5 倍スケール。
      2. Stickman が走って逃げる（4〜6 秒、pose: "run"、speed: 120-160px/s）。クマが後方 20px 以内を 150px/s で追跡（通常追従より高速）。
      3. 「⚠ クマ出没注意」看板（黄色・黒枠のトースト）が Stickman 前方 40px に 0.3 秒でフェード IN。
      4. 犬に戻る（0.8 秒、dogBehavior: "revert_to_dog"）。看板もフェード OUT。
    • 実装:
      • 行動定義: stickman/rare_bear_chase.json（"rare": true, "weight": 0）
      • 選出: MascotBehaviorEngine.PickNext() で通常プール選出より前に 1% 分岐
      • 描画: 犬部品にクマ用ブラシ＋1.5 倍スケールを適用、bearSignBorder を outerCanvas に配置
      • 新 dogBehavior コマンド: transform_bear / chase_stickman / revert_to_dog
      • 新フェーズフィールド: prop（MascotPhaseDto）で小道具キー指定

    コンパニオンの種別（テーマ連動とめんだこ）¶

    棒人間に付き従うコンパニオンは、適用中のテーマのカテゴリに応じて姿と動きが変わります。設定の「犬のコンパニオンを表示」を OFF にすると、いずれの種別も表示されません。

    テーマカテゴリ 種別 特徴
    Standard 犬 既定。忠実に追従する
    Lifestyle (WarmCozy) 猫 のんびり追従し、気まぐれに逆走・よく寝る
    Professional 小型ロボット 加減速のない等速移動。静止時にアイドリング揺れ
    Premium 大型犬 1.3 倍サイズでゆったり動く
    RetroTech ドット風ロボット 位置を 2px グリッドに量子化したカクカク移動

    ターミナル表示中は「めんだこ」¶

    ターミナルが画面に見えている間だけ、上表の種別に代わって めんだこ（Claude Code のマスコット）が現れます。

    • 判定: A/B ペインのターミナルタブ・ナビペインに埋め込んだターミナルのどちらでも対象。1 つでも表示されていればめんだこになり、すべて閉じる（または他のタブへ切り替える）とテーマ由来の種別へ戻ります
    • 配色: テーマの色には追従せず、常に Claude のサーモン色で描画します（他の種別は StickmanBrush に追従）
    • 動き: 接地せずに浮遊し、5 本の触手と耳ヒレをゆっくり動かします。走るポーズは漂う動きに置き換えられ、sleep では沈み込んで目を閉じます
    • 設定: Control Deck → Stickman の「ターミナル中はめんだこ」（既定 ON）。OFF にするとターミナル表示中もテーマ連動の種別のままになります
    • レアイベント「クマ出没」中はクマの演出が優先され、めんだこには置き換わりません
