    タブ操作¶

    A・B のペインは、それぞれ複数のフォルダをタブで開いておけます。開く・閉じる・切り替える・並べ替えるといった操作と、起動したときに何が戻るかをまとめます。

    できること¶

    したいこと 操作
    新しいタブを開く 「＋」、Ctrl + T、タブバーの空いたところをダブルクリック
    フォルダを裏のタブで開く 一覧のフォルダをマウスの中ボタンでクリック
    タブを閉じる 「×」、Ctrl + W、タブを中ボタンでクリック
    タブを切り替える クリック、Ctrl + Tab ／ Ctrl + Shift + Tab
    タブを一覧から選ぶ リストのボタン、または Ctrl + Shift + A
    並べ替える・反対のペインへ移す タブをドラッグ
    うっかり閉じないようにする 右クリック →「ロック」

    タブは A・B のペインごとに別々に並び、閉じるまで、それぞれのタブが自分の「戻る」「進む」の履歴を持ちます。アプリを閉じても、次に起動したときに同じタブが戻ります。

    使い方¶

    開く¶

    • 新しいタブ: タブバー右の「＋」、Ctrl + T、またはタブバーの空いたところをダブルクリックします。新しいタブはそのペインのホームフォルダを開き、いちばん右に加わります（ホームを設定していなければ、A ペインはデスクトップ、B ペインはダウンロード）。表示モードとアイコンの大きさは、それまで見ていたタブと同じになります。
    • フォルダを新しいタブで開く: ファイル一覧のフォルダをマウスの中ボタンでクリックすると、裏のタブで開きます。今見ているフォルダはそのままなので、ブラウザでリンクを中ボタンで開くのと同じ感覚で、行き先をいくつも開いておけます（設定の 基本設定 → ミドルクリックでフォルダを新しいタブで開く でオフにできます）。右クリックの「新しいタブで開く」でも開けます。
    • フォルダをタブバーへドロップ: フォルダをタブバーへドラッグして離すと、新しいタブで開きます。お気に入り・ツリー・参照履歴からドラッグしても同じです。複数のフォルダを落としたときは最初の 1 つだけを開き、ファイルは開きません。
    • ターミナルのタブ: 「＋」の右のボタンで、今のフォルダを作業場所にしたターミナルをタブとして開きます（サーバーのフォルダなど、作業場所にできないときはユーザーのフォルダで開きます）。

    閉じる¶

    • タブの「×」、Ctrl + W、またはタブをマウスの中ボタンでクリックします。中ボタンで閉じる操作は、ナビペインのターミナルのタブにも効きます。
    • ロックしたタブと、ペインに残った最後の 1 枚は閉じません。
    • 閉じたあとは、閉じたタブの右隣（右端を閉じたときは左隣）が選ばれます。
    • 閉じたタブを開き直す機能はありません。よく使う組み合わせは ワーキングセット に保存しておくと、まとめて呼び戻せます。

    切り替える¶

    • タブをクリックするか、Ctrl + Tab で次、Ctrl + Shift + Tab で前のタブへ移ります。端まで来ると反対の端へ戻ります。

    • タブの一覧: タブバー右端のリストのボタン、または Ctrl + Shift + A で、今のペインのタブが一覧で開きます。

      • クリックか、↑ ↓ で選んで Enter で切り替わります。
      • 各行の「×」、または選んで Delete か Ctrl + W で、そのタブを閉じます（ロックしたタブには「×」がありません）。
      • Esc か一覧の外をクリックすると閉じます。
      • A・B どちらのペインにいても、Ctrl + Shift + Alt + 1 で A ペイン、Ctrl + Shift + Alt + 2 で B ペインの一覧を開けます。

      キーは 設定 → ショートカットキー で変えられます。

    並べ替える・反対のペインへ移す¶

    • 並べ替え: タブを左右にドラッグします（10px 以上動かすとドラッグになります）。

    • 反対のペインへ: タブを反対のペインのタブバーへドラッグすると、落とした位置へ移ります。タブの右クリックからも操作できます。

      • 反対ペインに移動: タブごと移します。「戻る」「進む」の履歴もそのまま付いていきます。
      • 反対ペインに複製（Ctrl + N）: 同じフォルダを反対のペインに新しいタブで開き、元のタブは残します。
      • タブを複製（Ctrl + Shift + D）: 同じフォルダを同じペインに新しいタブで開きます。右クリックしたタブが対象なので、選んでいないタブも複製できます。

      複製したタブは、「戻る」「進む」の履歴を持たずに始まります。1 画面表示のときに反対のペインへ移したり複製したりすると、2 画面表示に切り替わります。

    ロックする・まとめてお気に入りへ¶

    • ロック: タブを右クリック →「ロック」。ロックしたタブは「×」の代わりに南京錠が出て、閉じられなくなります。外すときは右クリック →「ロック解除」。ロックは次に起動したときも残ります。
    • このペインのタブを全てお気に入りに追加: タブを右クリックして選ぶと、そのペインの全部のタブのフォルダを、新しい仮想フォルダにまとめてお気に入りへ登録します。フォルダ名と説明（任意）を入れてから保存します。存在しないフォルダと、すでに登録してあるフォルダは飛ばします。

    見た目を変える¶

    設定の タブ で変えられます。

    設定 選べるもの
    タブ幅 固定幅（下の「固定幅のサイズ」までの幅で、名前に合わせて縮む）／フォルダ名に合わせて可変幅（最大 600px）
    固定幅のサイズ 100・120・150（既定）・200・250px
    タブの折り返し 1 行（横スクロール）／複数行に折り返し
    タブ行の高さ同期 折り返すとき、A と B のタブバーの高さを揃えて、アドレスバーの位置を合わせる
    タブ管理ビュー連携 ナビペインで タブ管理ビュー を出している間、A・B のタブバーを隠す

    タブの文字の大きさは 表示 → タブの文字、切り替えたときの演出（中身のフェードと、下線のスライド）は 演出 → タブ操作のアニメーションを有効にする でオフにできます。

    しくみ¶

    起動したときに戻るもの¶

    • タブは、アプリを閉じるときに settings.json へペインごとに保存します。保存するのは、各タブのフォルダ・ロックの有無・種類（フォルダかターミナルか）と、選んでいたタブ、アドレスバーを入力欄にしていたか、表示モード・アイコンの大きさ・並べ替え、ペインのホームフォルダです。
    • 検索結果のタブは、ふつうのフォルダのタブとして戻ります（検索はやり直しません）。
    • 起動してすぐに中身を読むのは、選んでいたタブだけです。ほかのタブは、初めて切り替えたときに読みます。タブをたくさん残していても、起動が遅くならないようにするためです。
    • 基本設定 → 起動時に前回のタブを復元する をオフにすると、各ペインはホームフォルダ 1 枚で始まります。

    フォルダごとの表示の記憶¶

    基本設定 → フォルダ別の表示設定を自動復元する（既定でオン）がオンのときは、フォルダを離れるときに、そのフォルダでの並べ替え・表示モード・アイコンの大きさ・「フォルダを先に」を覚えておき、次にそのフォルダを開いたときに当てはめます。どのタブで開いても同じです。180 日使わなかったフォルダの記憶は消します。

    切り替えを速くする仕組み¶

    • 最近使った 6 枚のタブは、表示をそのまま手元に残しています。 切り替えると作り直さずに出すので、選んでいたファイルやスクロール位置も元どおりです。7 枚目のタブに切り替えると、いちばん長く見ていないタブの表示から手放します（選んでいるタブとターミナルのタブは手放しません）。手放したタブは、次に切り替えたときに表示を作り直します。
    • 見えていないタブも、フォルダの変化は見張っています。 外でファイルが増えたり消えたりしたら「読み直しが要る」と印を付けておき、切り替えたときに一覧を読み直します。見えていないあいだに何度も読み直して、手元の作業を重くしないためです。
    • 「戻る」「進む」の履歴はタブごとにメモリの中だけにあり、タブを閉じるかアプリを終了すると消えます。
