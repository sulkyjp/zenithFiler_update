    Menu¶

    Click ≡ at the right of the title bar, or press and release Alt (or press F10), to browse the app's features through pull-down menus, starting from a heading. Use the menu when you don't know what's there, and the Command Palette (Ctrl+Shift+P) when you know the name and want to type it.

    What you can do¶

    To Do this
    Browse for a feature ≡ → a heading → a submenu → the item
    Browse with the keyboard only Press and release Alt (or press F10) → the underlined letter of a heading, or pick one with Left / Right and press Enter
    Find a feature by name ≡ → Help → Find by name…, or Ctrl+Shift+P
    Open a heading from the keyboard While the menu is open, press the underlined letter of the heading (F for File)
    Bind a key to a feature The current key is shown at the right of each item. To change it, use Shortcuts in the Control Deck

    How to use it¶

    Headings and what's inside¶

    There are 9 headings. Every menu has at most 15 items, and nothing is more than three levels deep (heading ▸ submenu ▸ item).

    Heading What's inside
    File Open, open in a new tab or the other pane, Open with another app ▸, New ▸, Compress ▸, Extract ▸, Export and convert ▸ (Excel, CSV, PDF), properties, close the window, exit
    Edit Undo, redo, cut, copy, paste, copy or move to the other pane, Copy path or name ▸, rename, batch rename, batch timestamps, delete, Select ▸
    View Layout ▸, Sort by ▸, Group by ▸, Optimize this folder for ▸, showing extensions and hidden files, Split view ▸, Navigation pane ▸, Window ▸ (snapping, always on top, other screens), Preview ▸
    Go Back, forward, up, home, desktop, Downloads, the address bar, Quick Jump, Tabs ▸, Move focus ▸, Navigation pane views ▸, Favorites ▸, working sets
    Search Search, file content search, index search, filter in place, Filter ▸, saved searches, search history, Index ▸
    Tools Compare and sync ▸, hashes, recounting folder sizes, Terminal ▸, Connect and share ▸, File Explorer ▸, Macros ▸ (your saved macros are listed too), Screen capture ▸, the ring, Copy and move jobs ▸
    AI Turning generative AI on or off, AI manual, AI folder analysis, AI tab management, creating folders with AI, handing items to Claude
    Options Open the settings (Control Deck), and each Control Deck page (Basics, Appearance, Controls, Features, Collection and App ▸ each page, in the same order as the list on the left of the Control Deck)
    Help Find by name…, the manual, the changelog, Challenges ▸, feedback, logs

    Fine-grained actions such as choosing a tab by number or going back in a named pane (A or B) are not in the menu. Run them by name from the Command Palette, or bind a key to them.

    The menu bar with Alt or F10¶

    Press and release Alt on its own (no other key in between), or press F10, and the menu bar appears over the top of the active pane, as wide as that pane, so where it appears tells you which pane it acts on (the lower pane's top edge in a top-and-bottom split). It doesn't push the file list down, and it takes no screen space the rest of the time. In a narrow pane, the headings wrap onto two lines.

    Key What it does
    The underlined letter of a heading (F, E, V…) Opens that heading
    Left / Right Moves to the next heading (with a heading open, opens the next one)
    Down / Enter / Space Opens the selected heading
    Esc Closes the open heading; press again to close the menu bar
    Alt again, or F10 Closes the menu bar

    You can also click a heading to open it, and while one is open, just point at another heading to switch. Clicking outside the menu bar or running an item closes it.

    • It doesn't appear when you press Alt together with another key (such as Alt+D or Alt+Left), click while holding Alt, or are in the middle of IME composition
    • Inside the terminal, Alt goes to the program running there, so the menu bar doesn't appear
    • Click the button at the right end of the temporary bar (a panel opening upward) to switch to keeping it visible (this turns on Always show the menu bar, and each pane gets a bar above its tab strip)
    • To turn it off, clear "Show the menu bar with Alt or F10" under Shortcuts in the Control Deck (the ≡ menu still works)

    Keeping it visible¶

    By default, each pane has its own menu bar above its tab strip (Always show the menu bar under Shortcuts in the Control Deck, on by default). To get the space back, turn it off and the menu bar appears only when you press Alt or F10.

    • Each pane's menu bar acts on that pane (clicking it makes that pane active before it opens)
    • It uses the same background as the tab strip, and the active pane's bar takes the same highlight as its tab strip, so it fits in with any theme
    • The headings and the button at the right end use the same color and size as the icons at the right of the tab strip. The items in the open menus and their descriptions use the same color too (right-click menus keep their own colors)
    • In a side-by-side split the two bars sit at the same height and take one row; in a top-and-bottom split they take two
    • While it's always shown, Alt and F10 move to the active pane's menu bar (press again to go back)
    • Click the button at the right end of the bar (a panel folding upward) to hide the menu bar (this turns off Always show the menu bar). After that, Alt and F10 still show it just for that moment. Hovering over the button tells you this and where to turn the setting back on

    Heading underlines and motion¶

    The underlined letters in the headings (the key that opens each menu, such as F for File) are hidden normally and appear only while you hold Alt or are using the menu bar from the keyboard (the same as Windows 11). Only the underline changes, so the headings don't shift when you press Alt. The highlight behind the selected heading slides from heading to heading, and moving to the next heading while a menu is open swaps its contents in place instead of closing and reopening (no flicker). When a menu opens, a light runs once along the line under the selected heading. You can turn the motion off with Tab operations under Effects in the Control Deck (changes then happen instantly).

    Icons and what's currently on¶

    Every item has the same icon as on the toolbar or in the right-click menu. On/off items (show hidden files, show file extensions, always on top, generative AI and so on) show an accent-colored ✓ in place of the icon when they're on, and items where you pick one (layout, sort column and direction, group by) show an accent-colored ● on the current choice. The view marks reflect the selected tab in the active pane, and they're refreshed every time the menu opens. Each row in the command palette shows the same icon.

    Searching the menus¶

    Start typing while a menu is open, or while the menu bar is selected, and a search box appears just below the menu bar to search every menu (plus actions that are only in the command palette). The 🔍 at the right of the bar and / also start it. Each result shows the icon, the name, where it is in the menus (such as "View ▸ Sort by") and its key, so next time you can also find it by following the menus. Use ↑ ↓ to choose, Enter to run and Esc to go back. With the box empty, your recently used items are listed. If you type with an IME on, the box opens and you type again there.

    Recent items and Repeat¶

    Actions you run from the menu, the command palette or the menu search are remembered, newest first, up to 20, and ten of them appear under Recent (the clock icon) at the far left of the menu bar. Repeat: … in the Edit menu runs the last action again (it has no key; you can assign one under Shortcuts in the Control Deck).

    Right-clicking an item (assign a key, pin)¶

    Right-click an item in a menu or a search result for two options:

    • Assign a key…: opens the Shortcuts page of the Control Deck, filtered to that action
    • Pin to the menu bar: adds a button with the action's icon to the right of the headings (left of 🔍), up to 12. Clicking it runs the action, and on a per-pane menu bar it acts on that pane. Right-click a pinned button to unpin it, move it left or right, or assign a key

    Item descriptions¶

    Rest the pointer on an item for a moment (0.5 seconds) and a description appears below the menu, as wide as the menu (it never covers the items; if there's no room below, it appears above). Once one is showing, moving to the next item switches it straight away. Rows with ▸ (which open a submenu) don't show one. The description shows:

    • What it does: what the feature does and what it acts on (the selected items, the active pane, the whole folder and so on), plus things worth knowing (whether you can undo it, where it works)
    • Setting: where related settings are in the Control Deck (when there are any)
    • Also available from: the key assigned to it and the other places you can run the same feature (buttons in the title bar, tab strip, toolbar or status bar, right-clicking in the file list), and finally the name to type in the command palette. Button locations are read from the current screen, so they stay right even after you rearrange the toolbar

    To turn them off, clear Describe menu items on hover under Control Deck → Controls → Shortcuts (the reason an item can't be used still appears).

    Items you can't use right now¶

    Items you can't use in the current state are grayed out in the same place, not hidden, so the way to each feature never changes. Point at one to see why.

    • It doesn't apply to what you have selected (for example, comparing two text files when you haven't selected two)
    • It's a Pro feature and you've used up the free uses

    Pro features¶

    Pro features with free uses show how many are left after the name, such as "Pro · 2 left". When they run out, the item is grayed out. With a license registered, nothing is shown.

    How it works¶

    • The menu and the Command Palette are built from the same list of features. A feature you find in the palette has the same name in the menu.
    • Actions apply to the pane that was active when you opened the menu. Actions on files and folders apply to what you have selected in that pane (or the current folder when nothing is selected), exactly as the same item in the right-click menu would.
    • A submenu's contents are built when you open it, and rebuilt every time, so whether an item is grayed out and how many free uses are left always reflect the current state.
