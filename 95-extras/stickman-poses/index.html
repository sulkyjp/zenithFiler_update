    Dog Commands (dogBehavior)¶

    Setting dogBehavior on a phase gives special instructions to the dog.

    Command Description
    null (omit) Normal follow. The dog follows behind the stick figure
    run_ahead The dog runs ahead in the stick figure's direction
    watch The dog sits and watches the stick figure
    jump_from_head The dog jumps using the stick figure's head as a springboard
    somersault The dog imitates a somersault
    spin The dog spins rapidly in place (happy/excited)
    bark The dog hops in place excitedly, as if barking
    come_pet The dog trots to the stick figure's side and sits, tail wagging (pair with the pet pose)
    lie_down The dog lies down calmly (relaxed, submissive)

    Available Props (prop keys)¶

    Set "prop": "<key>" on a behavior phase to make a small prop fade in 40 px ahead of the Stickman. The same keys are usable from AI behavior generation.

    Key Display Typical scene
    coffee_cup ☕ いっぷく Break / idle
    umbrella ☂ Sad / rainy
    white_flag 🏳 降参 Surrender / overwhelmed
    boombox 🎵♪ Music vibe
    popcorn 🍿 Watching long process
    gold_medal 🥇 Achievement / completion
    broom 🧹 Cleanup / delete
    gift_box 🎁 Reward unlocked
    paper_airplane ✈ Sending file
    magic_wand ✨ 魔法 AI generation success
    hard_hat ⛑ 工事中 Indexing / under construction
    magnifier 🔍 Searching
    sleep_z 💤 zzz Long idle
    light_bulb 💡 ひらめき Tip / insight
    clipboard_check 📋 完了 Operation complete
    key_gold 🔑 解放 Level unlocked
    dumbbell 🏋 重い… Heavy operation
    boba_tea 🧋 Stylish break
    birthday_cake 🎂 おめでとう Anniversary
    caution_cone 🚧 作業中 Warning / editing
    bear_warning_sign ⚠ クマ出没注意 Rare event (bear chase)

    These props are built into the app, and every behavior can use them.
