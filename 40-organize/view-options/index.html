    View Options¶

    • Column width: Choose one of three ways to size the list's columns. The icon at the left end of the column headers always shows which one is in use.
      • Fit to window (icon ↔): The Name column takes the remaining width so the columns fill the window. As the pane narrows, Type, Size and Date Modified are hidden in that order, keeping at least 250px for Name (in search results the order is Location, Size, Date Modified, Name, and the Path column stays to the end). They come back when the pane widens
      • Fit to text (icon: left-aligned bars of different lengths): Each column is sized to fit all of its text, including long names further down the list (up to 60% of the window for Name and half of it for Path). Columns are refitted each time you open a folder, leaving space on the right. Reloading the same folder (F5 and so on) only widens columns, never narrows them. An empty folder leaves widths unchanged
      • Set by hand (icon ✋): Widths never change automatically. Widths you set by dragging column borders are remembered, including after a restart
      • Switching: Each click on the icon at the left end of the headers moves to the next mode: Fit to window → Fit to text → Set by hand. Right-click the icon or any column header for a menu with all three. You can also use the "Column width" button on the pane toolbar or "Switch column width mode" in the command palette. The choice applies to the lists in every pane and tab. When you switch, the columns slide to their new widths
      • Dragging a column: In Fit to window or Fit to text, dragging a column border switches to Set by hand (a notice appears the first time only; after that the icon at the left briefly lights up). Click the icon round to Set by hand again and your hand-set widths come back
      • In Fit to text and Set by hand, a horizontal scroll bar appears when the columns are wider than the window
      • New users start with Fit to text. If you used Zenith Filer before, you get Fit to window if the old "Auto-fit columns" was on, and Set by hand if it was off
    • Showing / hiding columns and fitting one column: Right-click a column header in the list to see the three column width modes followed by "Fit this column to text", which fits only the column you right-clicked, once (in Fit to window it switches to Set by hand). Uncheck a column name below them to hide that column — also the quickest way to make a column narrower. Pick it again to bring it back at a width that matches the current column width mode (the refitted width in Fit to text, the remembered width in Set by hand). The Name column cannot be hidden. The Date created, Extension and Attributes columns are hidden by default and can be shown here (as in File Explorer; attributes appear as single letters: R read-only, H hidden, S system, A archive, C compressed, E encrypted, O offline, L link, T temporary). In Fit to window, these three and the "More columns" below are the first to go when space runs short. Columns for information stored in files (date taken, dimensions, camera maker / model, length, bit rate, artist, album, genre, year, title, authors, tags, rating, pages, company and comments: 17 in all) are under "More columns ▶" in the same menu (like File Explorer's "More columns"; all hidden by default). Values are read starting from the rows on screen, so folders open just as fast. Sorting by one of them reads every item first and puts files without a value at the end (a progress bar appears for large folders and can be cancelled; 10,000 items take about a minute). Online-only files, network locations and archive contents are not read. Hidden columns apply to the lists in every pane and tab and are kept after a restart. Search results show the same menu, where the Location, Path, Date Modified and Size columns can be hidden. The Location column appears only in search results (in a normal list, the icon at the left end of the address bar shows what kind of place you are in).
    • Optimize this folder for: in the empty-space right-click "View ▶ Optimize this folder for ▶", pick General items, Documents, Pictures, Music or Videos (as in File Explorer). The folder's view changes and is kept for next time: Pictures is large icons sorted by date taken (oldest first), Music is details by name, Videos is large icons by name, Documents is details with the newest first, and General items is details with the default sort and no grouping. Column visibility is one setting for the whole app, so it is not changed per folder.
      • Applying it automatically: turn on "Adjust the view to each folder's contents" under Control Deck → "Display" → "Sort order" (off by default), and folders you have never opened get a type picked from their file extensions when you open them (when there are at least 3 files and the most common kind is at least half). Folders you have opened before keep the view remembered then (use the menu above to change them). Sorting Pictures by date taken re-sorts after the dates are read, once the list is shown.
    • Group by: right-click empty space and choose none, name, date modified, size or type from "Group by ▶" (like File Explorer's "Group by"). In Details view each group starts with a header band such as "Today (12)". The groups are: for dates, Today, Yesterday, Earlier this week, Last week, Earlier this month, Last month, Earlier this year, Last year and A long time ago; for sizes, Empty (0), Tiny (up to 16 KB), Small (up to 1 MB), Medium (up to 128 MB), Large (up to 1 GB), Huge (up to 4 GB) and Gigantic; for names, the first letter (symbols, 0 – 9, A – H, I – P, Q – Z, the kana rows and kanji); for types, the type name. Items within a group keep the current sort order, and the sort direction also flips the order of the groups (date modified, descending puts Today first). For size and type, the folder group comes first when folders are sorted first. The arrow (▾) at the left of a band collapses that group so only the band remains (click again to expand it). Clicking elsewhere on the band selects every item in the group (hold Ctrl to add them to the selection). Right-clicking a band shows the empty-space menu, where "Collapse all groups" and "Expand all groups" under "Group by ▶" switch them all at once. Collapsed groups stay collapsed while you stay in the folder, even as files come and go, and everything expands again when you move to another folder. The choice is remembered per folder. Icon views show no bands but keep the group order. The bands are hidden while type-to-filter is active, and collapsed groups show all their items during that time.
    • Cloud sync status: In sync folders such as OneDrive, Box Drive and Dropbox, Details view shows a mark next to the name (the same three as File Explorer's Status). A cloud means "online-only" (downloaded when opened), an outlined check means "available on this device" and a filled check means "always available on this device". Hover over the mark for a description. "Available on this device" appears only in Box Drive and OneDrive / SharePoint sync folders (other sync apps do not mark files with that state).
    • Folders first: Toggle between always showing folders above files or mixing them in name order.
    • Folder sizes: When you open a folder, the sizes of the folders inside it are counted in the background and shown in the Size column. They are counted the same way as Explorer's Properties, so the values match (hidden and system files are counted, the targets of junctions and symbolic links are not, and hard links are counted once per link). While counting, a small spinning mark appears in the Size column for folders that don't have a size yet.
      • Normal and dimmed text: Only sizes counted while you are viewing the folder appear in normal text. Sizes remembered from an earlier count (kept even after you close the app) and sizes from the index are dimmed until counting finishes, then switch to normal text. Dimmed text means the value may be out of date
      • Tooltip: Hover over a size to see the exact bytes, the number of files and folders inside, and when it was counted, such as 5.86 KB (6,001 bytes) / 3 files, 3 folders / Counted at 14:00, so you can compare without opening Properties. For a dimmed size, it says whether it is a previous value, a value from the index, or whether the contents changed after counting
      • Recounting: Press F5 to recount every folder in the list, or use "Recount size" on the right-click menu to recount only the selected folders, at any time. Places you move, copy, delete or rename in Zenith Filer are recounted on the spot
      • Changes while you're viewing: While a folder on a local drive is open, changes inside it (including changes made outside the app, for example in Explorer) are watched and the changed folders are recounted. Large folders that take a while to count (2 seconds or more last time) are not recounted; their size is dimmed instead (press F5 to recount)
      • Recount interval: A folder's modified date doesn't change when files deep inside it are added or changed, so by default folders are counted every time you open them. With a longer interval, the previous value is simply shown dimmed until that much time has passed
      • Sorting: When you sort by size, folders are ordered by their counted size. Rows don't move while counting is in progress; the list is re-sorted once when counting finishes (your selection and scroll position are kept)
      • Properties pane: When you select a folder, counting starts right away, as in Explorer's Properties; the running total grows in the form 5.86 KB (6,001 bytes), and the number of files and folders is added when it finishes. With multiple items selected, folder sizes are included in the total
      • Places that aren't counted: Network drives (\\server\share or mapped drives) and cloud-synced folders (Box Drive, OneDrive, SharePoint) aren't counted by default: network drives are slow and the counting puts load on the server, and in cloud folders the sync app has to respond for every folder, which tends to be slow (file contents are never downloaded). Servers (FTP / SFTP) are never counted. Even where sizes aren't counted, indexed locations show the index value dimmed
      • Indexed locations: The index value is shown dimmed at first and replaced with the same value as Properties once counting finishes (the index can differ from Properties because of its exclusion rules and update lag; see Index search)
      • If some folders inside couldn't be opened and only part could be counted, the size is shown with "≥", such as ≥ 12.3 GB (the real size is larger; Properties shows the smaller value without any mark)
      • Counting runs as a single low-priority background task that doesn't get in the way of other disk activity. It stops as soon as you move to another folder, and it doesn't start right after launch
      • Under Control Deck → "Display" → "File list", "Count folder sizes automatically", you can choose whether to count automatically (on by default), the recount interval (every time / 10 minutes / 1 hour / 1 day; every time by default), whether to also count on network drives, and whether to also count in cloud folders (both off by default, chosen separately)
    • Per-folder view settings auto-restore: Remembers the sort order, view mode, icon size, whether folders come first and the grouping for each folder, and applies them again when you come back. Toggle it with "Auto-restore folder display settings" under Control Deck → "General" → "Startup and exit" (on by default).
    • Second search bar row: An option that moves the search bar onto the second row of the header, but only in a side-by-side dual-pane layout. Freed from sharing a row with the icons, the search field and its filters get much more horizontal space. Toggle it with "Move search bar to second row in dual-pane mode" under Control Deck → "Search" → "Search bar" (off by default). With a single pane, or when panes are stacked vertically, the layout stays on one row regardless of the setting. Note that when a pane is too narrow for the search bar to survive on one row, it moves to the second row automatically, whatever the setting says — the history suggestions open at the width of the search box, so in a cramped bar the delete button at the right end of each row would be out of reach.
    • Alternate row colors (zebra striping): Tints every other row in the list a very subtle color, making rows easier to track in wide listings or listings with many rows (Control Deck → "Display" → "File list", "Alternate row colors"; off by default). Rather than a bold striped look, the shading stays subtle enough to never compete with hover/selection colors.
    • File-type coloring: Colors file names by category — images, videos, audio, archives, executables, documents, and code (7 built-in categories) (Control Deck → "File type colors", off by default). A recommended set of extension/color pairings ships out of the box, but every rule's extensions, color, and enabled state are fully editable, and you can add or remove rules freely.

    • Neither of these colors is a fixed value — both are computed automatically against the current theme's background color, so they always look natural whether you're on a bundled theme, an AI-generated theme, or a theme downloaded from the Theme Store.

    • Spotting what's new: Recently modified files and folders show their date in bold, and anything touched just now (within 10 minutes by default) gets a ✨ mark to the right of its name — the mark clears itself once the time passes. Pick the range under Control Deck → "Display" → "Markers", in "Spotting what's new": off, today, 24 hours, 3 days or 7 days; the ✨ mark can be turned off on its own (defaults: 24 hours, mark on). How long the ✨ stays is set just below, in "How long the ✨ mark stays", by typing a number and choosing minutes or hours (1 minute to 7 days; 10 minutes by default). If it is longer than the highlight range, the ✨ stays after the range ends. It exists to stop an old file being sent in place of the current one.

    • Network location marker: While a network folder is open, the tab and the address bar are tinted with the theme's accent and the tab icon becomes a globe. It recognises share paths such as \\server\share as well as mapped drives like Z:, so a shared server is never mistaken for your own machine (Control Deck → "Display" → "Markers", "Show when the folder is on a network"; on by default).
    • Shortcut target on hover: Hovering a shortcut (.lnk) shows its target's full path in a tooltip, and hovering an internet shortcut (.url) shows its URL, in both detail and icon view. A warning is shown if a shortcut's target can no longer be found. Since targets and URLs are read in the background after the list loads, they may appear a moment after the list itself shows up. A shortcut's (.lnk) target is also shown in the Properties view.

    Effects Categories¶

    In-app animations are grouped into categories that you can toggle individually via Control Deck → "Effects". If you want maximum speed, you can turn them off per category or all at once.

    Category (as named on the Effects page) Target UI / animation
    A. Startup & Global Welcome animation, the light around the card and the rippling title when you finish QuickStart, growing-bar animations (favorites, file sizes and so on)
    B. GlowBar Progress bar fade, interpolation, glow
    C. Scan Bar Scan bar while a folder loads
    D. Tab Operations Tab underline that follows as a light, fades when tabs open and close and on tab hover, insertion marker while dragging a tab
    E. Pane Transitions Pane fade, Control Deck opening and closing, width animation when switching between one and two panes and opening or closing the nav pane
    F. Theme Theme switch overlay, theme apply toast
    H. Quick Preview Hover thumbnail fade (moving to the next or previous file does not move the contents)
    I. File List Row hover, result glow, light that follows the selection, light on the row selected after a delete, fades for search pop-ups, the tab list, right-click menus and the key guide
    L. Drag & Drop File name label while dragging, drop target highlight, glow on the receiving folder, drop suck-in
    Feedback on actions Loading line on folder moves, colour change of the active pane, light on pane switching, light that follows the selected mark in Settings and the nav pane, buttons, dialogs, toasts, Quick Jump, the command palette and Quick Preview appearing

    Press Play under See the effects at the very top of the Effects page to watch, on a small sample, the light following the tab underline, the light on a landing row, the ring of light on ★, and the light running around a notice with its name rippling, one after another (they run on the same parts as the real screens).

    Turning on Turn off all effects (instant display) at the top of the Effects page stops D, E, F, H, I, L and Feedback on actions together. Whether the mascot is shown is set on the Stickman page.

    Automatic reduction on slow environments: When Automatically reduce effects on slow systems (on by default) is enabled, the app detects remote desktop sessions (RDP/VDI), software rendering, and environments where screen transitions are measurably slow, and disables the six decorative categories (D Tab Operations / E Pane Transitions / F Theme / H Quick Preview / I File List / L Drag & Drop) and Feedback on actions in one go. A toast notification is shown on detection. Progress indicators (B GlowBar / C Scan Bar) and A Startup & Global are not affected. The ON/OFF settings of each category are not modified, so turning this setting off makes effects play according to your settings as before. The same effects also stop when "Show animations" is turned off in Windows.

    Effects that make everyday actions feel smoother: The file list, tabs, drag and drop and more have effects that make it easier to see what just changed. They all follow the same idea: only a thin light moves, never the contents. The light comes from where the change started (the previous tab, pane or row), catches up as if following your hand, and melts away. When the same light repeats within a short time, the second one is fainter and shorter and from the third on it does not appear, so holding a key never makes the screen busy. It is the same motion as the ring launcher's light. They are built never to get in your way: the selection, the focus and the contents of the list are settled immediately regardless of any effect, and keys and clicks keep working while an effect is playing. Every one of them can be turned off on the Effects page.

    • Turn off all effects (instant display): At the top of the Effects page. When on, it stops the effects of D Tab Operations, E Pane Transitions, F Theme, H Quick Preview, I File List, L Drag & Drop and Feedback on actions, as well as the motion of the ring launcher and notifications, and switches the display instantly. While it is on, the per-category settings are greyed out (they are kept). A Startup & Global, B GlowBar and C Scan Bar follow their own settings. The mascot, even when turned on, does not walk while this switch is on, in lightweight mode, or when Windows' "Show animations" is off.
    • Feedback on actions: When you move to another folder, the list and the breadcrumb simply switch over with no motion (motion on every move gets in the way). Only when loading the destination takes 0.15 seconds or longer does a thin line run along the top of the list. When you switch to the other pane, a light runs along the new pane's edge from the side of the previous pane and melts away (the top edge when the panes are side by side, the shared edge when they are stacked). In the left navigation of Settings and the view icons of the nav pane, the selection mark moves at once and a light catches up from the previous position. Changing the colour of the pane you are working in, the button hover colour and a slight press-in when clicked, and dialogs, toasts, Quick Jump, the command palette and Quick Preview appearing also belong to this category. None of them move or resize anything; they appear by opacity alone (buttons do not grow on hover, and toasts do not rise but have a light run around their edge). When you expand a folder tree, its children appear at once.
    • D Tab Operations: When you switch tabs, the contents appear at once and do not move; the tab underline catches up from the previous tab with a short trail (it stretches on the way and shrinks to the tab's width when it arrives). A tab you open fades in, and a tab you close leaves an afterimage that fades away (closing itself does not wait). The fill when you point at a tab also fades in and out.
    • E Pane Transitions: Switching between one pane and two side-by-side panes opens and closes the panes with a width animation. The same happens when you swap A and B while staying on one pane, and when you open or close the nav pane in docked mode. Nothing moves at startup. Switches involving the top-and-bottom split and the auto-hiding nav pane behave as before.
    • I File List: When you move the selection to the next row with the arrow keys and similar keys, a light follows along the left edge of the list from the previous row to the new one and melts away. The selection itself moves the instant you press the key, so holding or tapping the key never makes you wait. It does not appear when you select with Shift or Ctrl held down, with the mouse, or when the move jumps off screen (PageDown, End and so on). The hover fill on rows fades in and out. After pasting, moving, creating or renaming, a light runs along the bottom edge of the affected rows from the left and melts away. For several rows it runs from top to bottom, each a moment after the last; when there are very many (more than 12), a single light outlines the whole list instead. The light uses whichever of the focus ring colour and the accent colour stands out more against the background. Rows you add to Favorites or index search light up the same way, as does the row the selection moves to after a delete. Right-click menus and the key guide also fade in.
    • L Drag & Drop: The highlight on the target folder fades in and out. When the folder receives the drop, a light spreads along the bottom edge of its row from where you released, and a snapshot of the rows you were dragging shrinks into it. Copying or moving starts the moment you drop and never waits for this effect. The suck-in does not appear for drops from outside the app, such as from Explorer, or for right-button drags.

    For new users, Feedback on actions is off by default (you can turn it on from the Effects page).
