    Theme Color Keys¶

    This is the full list of color items (keys) you can set in a theme JSON file, with where each one is used on screen. Use it together with Making a Theme File Yourself. The descriptions are the same ones shown in the theme customization screen.

    File layout¶

    • At the top level go Description.en (the description on the theme card; Description.ja and so on for other languages), Author, and Category (which category the theme is listed under: one of Standard, WarmCozy, Professional, Premium or RetroTech).
    • Setting Chrome to "Neutral" removes the touches that colors alone can't (the list's grid lines and selection outline, the glow lines and shadows on the title bar and toolbar, the emphasis on the selected tab and so on) for a plainer look close to File Explorer; the default theme Plain uses it. Leave it out to keep the usual look.
    • Colors go inside seven sections: Base, List, Search, Accent, ContextMenu, NavPane and Misc. Put each key in the section shown in the tables below. A key placed in a different section is silently ignored, just like a misspelled one.
    • Colors can be written as #RRGGBB, as #AARRGGBB with transparency (the first two digits are the opacity), or as a color name such as White.
    • A key you leave out follows the "If omitted" column. "= Xxx" means it takes the same color as that key, so changing the parent also changes children you haven't set. A color value means that color is used.
    • Line comments starting with // are allowed.
    • If a text color would blend into its background and become unreadable, some text colors are nudged automatically until they can be read.
    • To see which key colors what, click an item in the theme customization screen; the place where it is used flashes (see Theme Customization Auto-Navigation).

    Example: alternate row colors in the list¶

    • The color of every other row in the file list is ListAlternateRowColor in the List section. It shows when "Alternate row colors" is on under Settings > Display > File list.
    • If you leave it out, a subtle shade is derived from the background color (BackgroundColor) automatically. Setting it to the same color as the background counts as leaving it out; to remove the stripes, turn the setting off.
    • A semi-transparent value (#AARRGGBB) blends naturally over the active pane's tint as well. An opaque color is shown as is, even in the active pane.
    "List": {
  "ListAlternateRowColor": "#1A3A6EA5"
}

    The lists in the navigation pane (the left panel) don't have alternate row colors at the moment.

    There are 156 keys in all.
