    Text size¶

    You can set how large text is — overall, per area and per kind of text. The settings are on the Text size page in the Control Deck, right below Display.

    If you change nothing, everything looks the same as before.

    Size profiles¶

    A size profile keeps three things together: the overall scale, the per-area scales and Match sizes across the app. Profiles are listed at the top of the page.

    • Recommended: profiles that come with the app, tuned role by role
    Profile What changes What stays
    Matched Sizes that vary by area are brought to headings 14, body 13, secondary 12 and notes 11pt (see "Match sizes across the app" below) The overall scale
    Easier small text Notes go from 10 to 12pt, Control Deck descriptions from 11 to 12.7pt, shortcut keys, the search and filter bar and the terminal frame to about 12pt, tooltips and notifications to 13.2pt Body text, headings, lists
    Easier reading Body text goes from 12 to 13.8pt and the manual's articles from 14 to 16.8pt. Page headings get quieter, from 26 to 22pt Menus, lists, the main window
    More on screen Page headings go from 26 to 20.8pt, section headings from 14 to 13pt, body text and items about 1pt smaller Notes, descriptions, shortcut keys, tooltips (small text doesn't get any smaller)
    Screen sharing Extra large overall (×1.3), with the Control Deck held to about ×1.1. Notes, shortcut keys and tooltips go a little bigger still —
    - Mine: profiles you saved with Save current settings…. Saving under the same name overwrites. You can keep up to 30
    - Apply replaces all three at once. Right afterwards, Undo puts back what you had (until you leave the page)
    - You can Rename and Delete your own profiles. Export… saves one as a .json file, and Import… brings it in on another PC (an imported profile isn't applied until you press Apply)
    - The profile that matches your current settings has a ● next to it. You can also pick one under Text size profile on the Display page

    Overall size (five presets)¶

    The simplest way is to pick one of five overall sizes.

    Preset Scale
    Compact 0.9×
    Standard 1.0× (default)
    Large 1.15×
    Extra large 1.3×
    Maximum 1.5×

    The same five presets are also under Text size (overall) on the Display page. Fine-tune per area → takes you to the Text size page.

    Match sizes across the app¶

    Regular text is 11 to 13pt depending on where it is: menus, the Control Deck, the file list bars, the navigation pane and dialogs. Turn on Match sizes across the app to bring it all into four tiers.

    Tier Size Main examples
    Heading 14pt Control Deck section headings, navigation pane headings, dialog titles
    Body 13pt Menu items, Control Deck setting names and body text, the address bar, the search and filter bar, tabs, the navigation pane tree and body text, preview, dialog body text
    Secondary 12pt Title bar, status bar, column headers, tooltips, notifications, Control Deck descriptions
    Note 11pt Shortcut keys in menus, and small notes everywhere
    • Text only gets bigger to match. Nothing gets smaller
    • It works together with the five presets (for example Large with sizes matched). Multipliers you set per area or per kind of text apply on top of the matched sizes
    • Control Deck page headings, the first-run guide titles, the manual's article text and List text keep their sizes. Tab text is matched only while it's on Auto
    • The same switch is on the Display page. It's free to keep

    Per area and per kind of text¶

    On the Text size page you can set three things:

    • All: a slider from 0.8× to 1.5×
    • Area: a scale for each area, such as menus (0.7× to 1.6×)
    • Kind of text: a scale for each kind of text inside an area (for menus, "Items" and "Shortcut keys")

    Click an area's row to open the rows for the kinds of text inside it.

    The scales multiply. For example, with All set to Large (1.15×) and Menus at 1.2×, menu items end up at 1.15 × 1.2 = 1.38×. If you switch the overall preset later, the differences you set per area stay as they are.

    • Each row shows the resulting size in points. Hover over it to see how it was worked out (all × area × kind …)
    • The sample text in each row shows that size
    • The button at the end of a row puts just that row back to standard (1.0×). Reset all to standard puts everything back

    These 11 areas can be set. Text on buttons, check boxes, radio buttons and drop-down lists follows the "Body text" scale of the area it sits in.

    Area Kinds of text
    Menus (right-click menus and the menus opened from the buttons at the top) Items, shortcut keys
    Control Deck Page heading, section heading, setting name, body text, description, small notes, left-side list
    Main window Title bar, status bar, address bar strip, body text (working sets, the key guide, window layout menus and similar), small notes
    File list List text and Tab text (set in points), column headers, group headers, search and filter bar, small notes
    Navigation pane Tree and lists (rows in the folder tree, history, recent items and similar lists), headings, body text (body text, input boxes and buttons in views such as search, properties and AI), small notes
    Preview Body text, small notes (preview in the navigation pane, Quick Preview and the text comparison)
    Terminal frame Frame text (tabs, buttons, the settings window), action menu. Text inside the terminal is still set in the terminal settings
    Dialogs Title, body text, small notes (Folder Compare, Batch Rename, Macro Studio, the theme and AI dialogs, confirmation and input windows and more. Rows of lists inside dialogs grow with "Body text")
    First-run guide Title, body text (Welcome, First 5 steps and What's New)
    Tooltips and notifications Tooltips, notifications (the notification window shown when a copy finishes and so on)
    Manual window Frame text (the top bar, contents and the strips at the ends of articles), body text (the text, headings and code of manual and changelog articles)

    In the Control Deck, text with no size of its own, such as input boxes and lists, grows with the "Body text" scale. Places whose height is set by a number of lines, such as theme card descriptions, grow taller along with their text.

    Smaller text inside file list rows (the second line in Content view, the details in Tiles view, captions in icon views) has no scale of its own. It grows in proportion to List text (with List text raised from 14 to 18, 11-point text becomes about 14), so names and the other text in a row stay in balance.

    Text inside the rows of the navigation pane's folder tree, history, recent items and similar lists works the same way: dates and small marks grow together with the "Tree and lists" scale. Favorite names and descriptions are still set in points in the favorites settings (the "Tree and lists" scale doesn't apply to them).

    Set per screen¶

    Turn on Set per screen to show a Per screen list inside an area, where you can set a scale for each Control Deck page, for parts of the main window (working sets, the key guide and so on), for each navigation pane view (search, properties, the tab list and so on) for the preview and terminal windows and for each dialog (for example, larger descriptions on the AI page only). The screen's scale and the scales for kinds of text on that screen multiply as well.

    • Areas that have per-screen values show a mark (●) next to their name
    • Reset all per-screen settings in this area puts all of an area's per-screen values back at once
    • Turning the switch off keeps the values you set in effect (it only hides the list)

    While you drag a slider¶

    • Sliders for menus, the main window, the file list, the navigation pane, dialogs and the other areas outside the Control Deck change the app live while you drag. The value is set when you let go
    • The overall slider and the Control Deck sliders only change the sample text in their row while you drag, and apply when you let go. Applying them while dragging would reflow this page itself and move the slider out from under your mouse
    • If you move a slider with the arrow keys, it is set a moment after you stop

    List text and Tab text¶

    List text and Tab text are still set in points, as before (the same settings also appear under "File list" on the Text size page).

    • On Auto, the overall scale applies to them (14pt on Auto becomes 18.2pt at Extra large)
    • When you've picked a number, it stays exactly that number and the overall scale doesn't apply. The page shows a note saying so. Set it back to Auto if you want it to follow the overall size

    Ask AI¶

    In Ask AI at the bottom of the page, write how you want the text to change and press Ask AI (or Ctrl+Enter). The AI picks the global, area and role multipliers and tries them out right away.

    • For example: "Make everything a little bigger, but keep the file list as is" or "The descriptions in Control Deck are hard to read"
    • The AI picks the shallowest change that does the job ("make everything bigger" changes only the overall size; "Control Deck is hard to read" changes only the Control Deck area). It uses per-screen values only when Set per screen is on and you name a screen
    • The answer shows a short explanation and What changed (changes such as ×1.00 → ×1.20)
    • Apply keeps it, and Discard goes back to the sizes from before you asked. Refine… asks for more changes on top of the current result
    • If you leave the page or close the Control Deck without pressing Apply, the sizes go back to what they were before you asked
    • The AI never changes List text or Tab text (they are set in points)
    • It uses the AI chosen on the AI page. If AI is turned off or no AI service is set up, a message and a button to open the AI page appear

    What's free¶

    • The five presets (Compact, Standard, Large, Extra large, Maximum) can be kept by anyone
    • Match sizes across the app can also be kept by anyone
    • Anyone can save, rename, delete, export and import size profiles. Recommended profiles keep their per-area scales for everyone. Without Pro, applying one of your own profiles keeps the overall scale (the nearest of the five presets) and size matching, and the per-area scales are a trial. Moving a slider after applying a recommended profile is a trial too
    • The sliders, the per-area and per-kind settings and Ask AI can be kept with Pro (there is no limit on how often you ask the AI). Without Pro you can still move them and try them out live. While you're trying them, a banner shows at the top of the page, and everything goes back when you leave the page or close the Control Deck
    • If you stop having Pro, the values you set per area are kept but not applied (the nearest of the five presets is used instead). They come back as they were when you have Pro again
